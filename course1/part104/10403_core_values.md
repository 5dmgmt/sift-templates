## Step 1: まず自分で書く

Claudeに渡す前に、まず自分で以下を書いてください（10分）:

1. Phase 10401・10402を通じて繰り返し出てきたキーワードを、思いつく範囲で挙げてください (件数は問わない / 該当なしは理由)
2. 「これだけは絶対に譲れない」と直感で感じるものがあれば挙げてください (件数は問わない / 0 件 + 理由 でも完了)
3. 自分の価値観について、まだモヤモヤしていること・引っかかっていることは？

※ 正解はありません。頭で考えるより、体の感覚（胸がザワつく、スッと落ちる等）を信じてください。

**対話を深めるための補助情報 (シノファンシー = 過度な同意)**:
AI との深い対話では、応答が肯定的に揃いやすい場面が起こりえます (Anthropic 研究 2026)。
これは Claude の限界ではなく、対話のメカニズムとして知っておく豆知識です。
多くの応答は本来の共感・支持で問題ありません。ただし「ここは大事な決断だ」「もう一段
別の角度から見たい」と感じた時に、以下の選択肢を持っておくと役立ちます:
- 反対の立場から論拠を出してもらう (「逆の意見だとしたら何？」)
- 第二意見を別 Claude session で取る
- 「私の判断で見落としている前提があれば該当する分だけ挙げて」と頼む (件数は問わない)
Claude を疑い続ける必要はありません。Claude との信頼ある対話を保ちつつ、
検証ツールを「必要な時に使える」状態にしておく、それだけで十分です。

### Step 1: 価値観候補を広く出す (Claude が抽出)
10401 と 10402 から見えた「満たされた要素」「侵害された価値」を Claude が一覧にし、類似するものをグルーピングしながら候補を広く提示する (件数は問わない / 絞り込み元として十分な量を目安)。
抽象的すぎる言葉 (例: 「幸せ」) はもう一段具体化する。受講者に「違和感はあるか」を 1 問だけ聞く。

### Step 2: 中間絞り込み (Claude の問いで絞り込み、本人が判断)
以下の比較軸を Claude が表で提示し、候補それぞれに簡易スコア（◎ / ○ / △ / × など）を振る:
- **非交渉性**: これを諦めるくらいなら別の選択をするか
- **自分由来**: 他人の期待ではなく自分の本音か
- **経営判断への効き方**: 実際の意思決定で使える解像度か
- **10401 / 10402 の根拠**: 具体エピソードの裏付けがあるか
- **重複度**: 他の候補と意味が重なっていないか

そのスコア表を見せたうえで、以下の問いを 1 ターン 1 問で投げ、候補を絞り込む (件数は問わない / 本人の実感として湧く数で OK):
- 「これがない人生は考えられないか？」
- 「他の価値観と重複していないか？」
- 「他人の期待ではなく、自分の本音か？」

判断は受講者が行う。Claude は問いと候補提示のみ。

### Step 2.5: 中間絞り込みの一言定義を本人の言葉で確定する
中間絞り込み後、Claude が各価値観に **本人の言葉での一言定義案** を提示し、1 ターン 1 件で本人に確認・修正してもらう。10401 / 10402 の引用を 1〜2 個添える。Claude が定義を勝手に確定せず、必ず本人の OK を取る。

### Step 3: コア価値観に優先順位をつける (トレードオフ問い)
中間絞り込みの中から「判断で絶対に譲らない」コア価値観を本人が決める (件数は問わない / 本人の実感で OK)。Claude は以下のトレードオフ問いを 1 ターン 1 問で投げる:
- 「A と B が両立しない場面で、どちらを取るか？」
- 「この価値を捨てたら、自分が自分でなくなるか？」

最終的な優先順位は必ず本人が決定。Claude は決めない。

### Step 4: コア価値観に判定例を書く
コア価値観それぞれに以下を Claude が提案して、受講者が確認・修正する:
- **守られている行動の例**: この価値観が活きている日常の場面
- **壊れる行動の例**: この価値観が侵害される場面
