2. 1週間の業務時間のうち、得意なことに使えている割合は？（体感でOK）
3. 「本当は手放したいが手放せていない役割」があれば書いてください
4. 「もっと時間を使いたいのに使えていないこと」は？

※ 正解はありません。今の感覚で書いてください。Phase 10301・10302の成果物も手元に用意してください。

**対話を深めるための補助情報 (シノファンシー = 過度な同意)**:
AI との深い対話では、応答が肯定的に揃いやすい場面が起こりえます (Anthropic 研究 2026)。
これは Claude の限界ではなく、対話のメカニズムとして知っておく豆知識です。
多くの応答は本来の共感・支持で問題ありません。ただし「ここは大事な決断だ」「もう一段
別の角度から見たい」と感じた時に、以下の選択肢を持っておくと役立ちます:
- 反対の立場から論拠を出してもらう (「逆の意見だとしたら何？」)
- 第二意見を別 Claude session で取る
- 「私の判断で見落としている前提があれば該当する分だけ挙げて」と頼む (件数は問わない)
Claude を疑い続ける必要はありません。Claude との信頼ある対話を保ちつつ、
検証ツールを「必要な時に使える」状態にしておく、それだけで十分です。

### Step 1: 現在の業務を棚卸し (4 補助観点を順に / 件数は問わない)
以下 4 補助観点を順に聞いて、各観点で genuine な業務を抽出する (件数は問わない / 該当なしも genuine):
- 定例業務（毎日 / 毎週 / 毎月やること）
- 意思決定責任（自分しか判断できないもの）
- 突発対応（トラブル処理、相談対応）
- プロジェクト（現在進行中のもの）

### Step 2: 得意 / 消耗にマッピング (Claude が抽出)
洗い出した業務を、得意クラスター (10301) と消耗パターン (10302) に Claude がマッピングして提示。どちらにも当てはまらないものは「中立」として記録。

### Step 3: 残す / 外す / 委任に仕分ける (Claude が抽出 + 受講者承認)
マッピング結果をもとに Claude が以下 3 カテゴリの仕分け案を提示:
- **残す**: 得意クラスターに合致し、自分がやるべき業務
- **外す**: 消耗パターンに合致し、廃止または大幅縮小できる業務
- **委任候補**: 消耗するが必要な業務で、他者に任せられるもの

各カテゴリは件数を問わない。**該当が少ない or 0 件の場合は無理に捻出せず、その旨と理由を明記**（例: 「外すはほぼなし。残り業務はすべて経営者本人の責任範囲」/ 該当なしも genuine）。各分類の根拠が記録されていれば OK。
受講者に「この仕分けで OK か、入れ替えるか」を 1 問だけ聞く。経営判断に関わる「外す」項目は【要承認】マークを付ける。
