## 完了条件 (件数主義ではない / Phase 30201 / 30202 と継承)

- 件数主義を採らない。整合済み項目 (= 戦略的順序判断 / 別経路で代替済み / すでに着地 等) は genuine なギャップではないので、ギャップとして起こさず記録のみで完了
- ギャップを件数で完了条件にすることは禁止。捻り出した「強いて言えば」レベルのギャップは記録対象外 (混入時はそう注記する)
- 本人の実感として湧くもののみ残す

**2 層の見分け (Claude の役割 / Phase 30201 / 30202 と継承)**:
- **人間的な欲レイヤー**: 「もっと時間を使いたい」「使えていない」等の表層
- **深層の受容レイヤー**: 「整合している / 戦略的順序として正しい / 別経路で満たされている」等
- 両方が並走する応答 (例: 「使えていない (人間的な欲) / でも順序として正しい (深層の受容)」) は両方そのまま記録。整合済みを「ギャップ」に変換しない

### Step 0: 作業ファイル + 参照ファイルを読み、必要情報を揃える

### Step 1: 直近 2 週間の時間配分を可視化する（決め打ち）
Claude が以下 12 カテゴリの 1 週間平均時間を、事前メモから抽出 + 推定して提示する (合計 168 時間 = 24 × 7):
- 睡眠 / 仕事:会議 / 仕事:作業 / 仕事:メール&チャット / 仕事:移動 / 家族・パートナー / 友人・コミュニティ / 趣味・クリエイティブ / 運動・健康 / 学び / SNS・ニュース・動画 / その他

提示後、受講者に「時間配分に違和感があるカテゴリはあるか」を 1 問だけ聞き修正する。

### Step 2: 大切なもの × 現状投入時間の照合
30202 の Non-Negotiables それぞれ (件数は問わない / 10 件は目安) に、Claude がまとめて以下 3 項目を埋めた表を提示する:
- **理想の時間/週**: そのものを守るために必要な時間
- **現状の時間/週**: Step 1 から推定
- **ギャップ**: 理想 − 現状 (h)

提示後、受講者に「ギャップに違和感がある項目はあるか」を 1 問だけ聞く。

### Step 3: 是正が必要な genuine なギャップ
Claude が genuine なギャップ (件数は問わない / 5 件は目安 / 整合済み項目はギャップとして起こさない) を選び、各項目について以下 4 項目を埋めて提示する:
- **大切なもの**: Non-Negotiables のどれか
- **現状**: ギャップの大きさ + 現状の使い方
- **原因**: なぜ時間を使えていないか / 何に奪われているか / **整合済みなら "整合理由"**
- **次週の修正案**: 1 週間で試せる小さな変更 / **整合済みなら "修正不要"**

提示後、受講者に「修正案を変えたい項目はあるか」を 1 問だけ聞く。
最後に Claude が「Part 302 の統合メモ (後悔から見えた大切なもの / Non-Negotiables 上位 / 最大のギャップ)」を 3 行でまとめる (件数は問わない / 上位 3 件は目安)。
