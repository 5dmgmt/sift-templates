## 進め方（私に確認を取らずに開始してください）

### Step 0: 作業ファイルを読み、必要情報を揃える
1. `~/sift/course3/part302/30201_deathbed_regrets.md` を Read で開き、Step 1 セクションの事前メモを取得
2. 事前メモが空欄なら、以下 3 問をまとめて 1 度に提示し、私の答えを待つ（A/B/C 選択肢は出さない）:
   - 今の自分にとって本当に大切なものを 3 つ、理由なしで直感で挙げる
   - 「もし明日死ぬなら、今日何をするか？」の答え
   - 最近「後回しにしている」と自覚していること
3. 事前メモが揃ったら確認や進め方ヒアリングをはさまず即 Step 1 へ

### Step 1: 5 観点で後悔を引き出す（1 ターン 1 観点）
以下 5 観点を 1 ターンに 1 つずつ、Claude が問いかけ + 受講者の答えを引き出す形で進める:
1. **やらなかった後悔**: 挑戦しなかった / 始めなかった / 続けなかったこと
2. **言わなかった後悔**: 伝えたかった言葉 / 謝りたかったこと / 感謝
3. **過ごし方の後悔**: 誰ともっと一緒に / どこに行きたかったか
4. **仕事の後悔**: 引き受けるべきでなかった仕事 / もっと打ち込むべきだった仕事
5. **自分自身への後悔**: 自分を大切にしなかったこと / 無視した直感

5 観点合計で **5-10 件** が出れば次へ進む (無理に 20 件を目指さない)。
書けない項目は空欄のまま OK と Claude が必ず伝える。感情が溢れる発言が出たら、整理せずそのまま記録する。

### Step 2: 各後悔の「なぜ」を 3 項目で掘る
全後悔について、Claude がまとめて以下 3 項目を埋めた一覧表を提示する:
- **なぜ後悔するか**: 1〜2 行
- **本当は何を大事にしたかったか**: 1 行
- **今からでも間に合うか**: Yes / No / 一部 + 理由

提示後、受講者に「修正したい後悔はあるか」を 1 問だけ聞く。
最後に Claude が「後悔から見えた本当に大切なもの」を 3〜5 項目に絞って提示する (次 Phase 30202 への橋渡し)。

### Step 3: 成果物を vault に書き戻す
`~/sift/course3/part302/30201_deathbed_regrets.md` の Step 3「成果物」セクションを Edit で書き込む。
- ファイルの Step 1 / Step 2 (このプロンプト) は触らない
- Step 3 のやらなかった後悔 / 言わなかった後悔 / 過ごし方・仕事・自分自身の後悔 / 本当に大切なもの / 今からでも間に合うこと / 次の Phase へのメモ を埋める
- チェックリストの該当項目に ✓ を入れる
- 上書き前に必ず Read で現状を確認し、Step 3 が書き込み済みなら私に確認

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 私が別途確認すべき点があれば最後にまとめる
- 感情が溢れてもそのまま記録。「客観的に」整理しすぎない
- 感情的に辛くなったら途中で止めて OK。書けるところだけで十分
