## やること

このワークは任意です。「あと24時間で人生が終わる」という仮定から後悔を眺める方法と、死や後悔を使わず今後大切にしたいことから考える方法を選べます。

## Step 1: まず自分で書く

Claudeに渡す前に、まず自分で以下を書いてください（10分）:

1. 今の自分にとって本当に大切なものを、理由なしで直感で挙げる (件数は問わない / 思い浮かぶ分だけ)
2. 「もし明日死ぬなら、今日何をするか？」の答え（この問いを扱わない場合は、今後大切にしたいこと）
3. 最近「後回しにしている」と自覚していること

※ 正解はありません。このワーク自体を保留することも、死や後悔を使わない別ルートを選ぶこともできます。

**対話を深めるための補助情報 (シコファンシー = 過度な同意)**:
AIは、会話の流れによって同意寄りの応答を返すことがあります。
重要な判断では、反対意見、Claude のサブエージェントの意見、一次資料も参考にし、最終判断はご自身で行ってください。
多くの応答は本来の共感・支持で問題ありません。ただし「ここは大事な決断だ」「もう一段
別の角度から見たい」と感じた時に、以下の選択肢を持っておくと役立ちます:
- 反対の立場から論拠を出してもらう (「逆の意見だとしたら何？」)
- 第二意見は、Claude にサブエージェントで取ってもらいます
- 「私の判断で見落としている前提があれば該当する分だけ挙げて」と頼む (件数は問わない)
Claude を疑い続ける必要はありません。Claude との信頼ある対話を保ちつつ、
検証ツールを「必要な時に使える」状態にしておく、それだけで十分です。

### Step 1: 選んだルートで大切なことを眺める（1 ターン 1 観点）
後悔を扱うことを本人が選んだ場合は、以下 5 観点を 1 ターンに 1 つずつ進める。別ルートを選んだ場合は、同じ順序で「今後大切にしたいこと」「伝えたいこと」「大切にしたい過ごし方・仕事・自分自身」を尋ねる:
1. **やらなかった後悔**: 挑戦しなかった / 始めなかった / 続けなかったこと
2. **言わなかった後悔**: 伝えたかった言葉 / 謝りたかったこと / 感謝
3. **過ごし方の後悔**: 誰ともっと一緒に / どこに行きたかったか
4. **仕事の後悔**: 引き受けるべきでなかった仕事 / もっと打ち込むべきだった仕事
5. **自分自身への後悔**: 自分を大切にしなかったこと / 無視した直感

**完了条件 (件数主義ではない)**: 各観点で **本人の今の実感に沿う答え** が出れば次へ進む。本人の今の実感に沿う答えとは:
- 具体的な後悔 (件数は問わない / 1 件でも 5 件でも可)
- または「ない」「すでに着地している」「全て最善最適」「任せている」「在り方で答えている」等の **受容応答 + その理由**

両方とも Phase 30202 の素材として等価に扱う。

**応答の二重性の見分け (Claude の役割)**: 各応答について、Claude は以下の 2 つの観点を並べて記録する:
- **今も残る願い・違和感**: 願望・引っかかり・「広げきれなかった」等の感覚
- **受け入れられている実感**: 「すでに着地している / 全て最善最適 / 任せている / 在り方で答えている」等

両方が並走する応答 (例: 「広げたかった (今も残る願い・違和感) / でも届くべき所には届くと知っている (受け入れられている実感)」) は **両方そのまま記録** する。どちらかに寄せて整理しない。
- どちらも同じ重さの本人の言葉として扱い、深い・浅い、良い・悪いを付けない。

書けない項目は空欄のまま OK と Claude が必ず伝える。感情が溢れる発言が出たら、整理せずそのまま記録する。

### Step 2: 各後悔の「なぜ」を 4 項目で掘る (観点含む)
全後悔について、Claude がまとめて以下 4 項目を埋めた一覧表を提示する:
- **観点**: 今も残る願い・違和感 / 受け入れられている実感 / 並走 / 該当なし
- **なぜ後悔するか (または なぜ後悔がないか)**: 1〜2 行
- **本当は何を大事にしたかったか (または 大事にできていること)**: 1 行
- **今からでも間に合うか**: Yes / No / 一部 / 継続中 + 理由

「すでに着地している観点」も別表に必ず記録する (= 受容応答も本人の今の実感に沿う答えとして失わない)。

提示後、受講者に「修正したい後悔はあるか」を 1 問だけ聞く。
最後に Claude が「対話全体から見えた本当に大切なもの」を本人の実感として湧いた数だけ提示する (件数は問わない / 0 件 = すでに着地でも完了 / 3〜5 件は目安、次 Phase 30202 への橋渡し)。**今も残る願い・違和感と受け入れられている実感の両方を素材として扱う**。

## ルール
- **本人の希望を優先**し、途中で保留・休止・別の問いへの変更を選べるようにする。答えたくない理由は求めない
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 私が別途確認すべき点があれば最後にまとめる
- 感情が溢れてもそのまま記録。「客観的に」整理しすぎない
- 感情的に辛くなったら途中で止めて OK。書けるところだけで十分
