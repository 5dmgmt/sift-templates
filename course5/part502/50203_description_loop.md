## やること

### Step 1: 周回 1 — 初回 Description（1 ターン）
Claude が 50202 の学びを踏まえて初回プロンプトを設計し、想定出力 (要約 5-10 行) と 3 観点 (Product / Process / Performance、各 1-5 点) でレビューする。
改善点を Claude が特定して提示し (件数は問わない)、受講者に「修正したい点はあるか」を 1 問だけ聞く。

### Step 2: 周回 2 — 改善した Description（1 ターン）
Claude が周回 1 のレビューに基づいてプロンプトを修正し、変更点を明記。想定出力 + 3 観点レビュー + さらなる改善点を提示し (件数は問わない)、受講者に「修正したい点はあるか」を 1 問だけ聞く。

### Step 3: 周回 3 — さらに改善した Description + 3 周振り返り（1 ターン）
Claude が周回 2 のレビューに基づいてプロンプトを修正し、変更点を明記。想定出力 + 3 観点レビューを提示。
3 周を通じた以下を Claude がまとめて提示する:
- **進化サマリ表**: 周回 1/2/3 × 3 観点
- **最も効果があった改善パターン** (件数は問わない / 根拠付き)
- **自分の Description 力の現在地** (簡潔に)
- **次にやるならここを変える** (件数は問わない)
- **逆効果だった改善 (failure_log)** (件数は問わない / 該当なしも genuine)
- **損徳得厄メモ** (任意 / 該当なしも genuine / 本書 7-5 / 7-6): 逆効果だった改善は「短期得 (頭で得を追う) / 長期厄」の判断だったか / 効果があった改善は「ハートで愛を出す / 短期損・長期徳」の判断だったか

最後に受講者に修正案を 1 問だけ聞く。

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 各周回の改善点は具体的に記述する (「良くなった」ではなく何がどう変わったか)
- 3 周目でも完璧である必要はない。「次にやるならここを変える」を残して OK
- 改善が逆効果だったケースも記録する (failure_log)。失敗パターンは今後の資産
