## 背景
私はSIFTのCourse 5「AI Fluency — AIを扱う力」Part 502「任せる + 伝える」に取り組んでいます。
このPhaseでは、Description（記述）の能力を実践的に鍛えます。

### Description の3つの構成要素（Anthropic Academy）
- **Product Description（成果物の記述）**: 何を作ってほしいか明確に定義する（出力、形式、対象読者、スタイル）
- **Process Description（プロセスの記述）**: AIがどう取り組むかを導く（ステップバイステップの指示）
- **Performance Description（パフォーマンスの記述）**: AIの振る舞いを定義する（簡潔/詳細、挑戦的/支持的）

### 6つのプロンプト技法（Anthropic Academy）
1. コンテキストを与える
2. 例を見せる
3. 制約を指定する
4. 複雑なタスクをステップに分ける
5. AIにまず考えさせる
6. AIの役割やトーンを定義する

> 秘密兵器: AI自身にプロンプトの改善を手伝ってもらう!

## やってほしいこと

### Step 1: 3段階のプロンプトを作成
選んだ業務について、以下の3段階のプロンプトを一緒に作りましょう:

**Level 1: 曖昧な指示**
- 事前メモの「いつもの指示」をそのまま使う
- 何も補足せず、短い依頼文だけ

**Level 2: 構造化した指示**
- Product Description を追加（何を、どんな形式で、誰向けに）
- Process Description を追加（ステップを明示）
- 制約を追加（文字数、トーン、NG項目）

**Level 3: 文脈付き指示**
- Level 2 に加えて Performance Description を追加
- 背景情報（自社の状況、過去の経緯）を付与
- 例（良い出力のサンプル）を添付
- AIの役割を定義

### Step 2: 各プロンプトで出力を取得
3つのプロンプトをそれぞれ実行し、出力を記録します。

### Step 3: 品質比較
3つの出力を以下の観点で比較してください:
- 正確さ: 事実関係は正しいか
- 具体性: 自社の状況に合った内容か
- 実用性: そのまま使えるか、修正が必要か
- 効率: かかった時間と手戻りの少なさ

### Step 4: 成果物にまとめる
最終的に以下の形式でMarkdownにまとめてください。

## ルール
- 根拠がある部分と、推測の部分を分けて出力してください
- まだ確定していない暫定判断には【仮説】マークをつけてください
- 3段階の「差」を具体的に記述してください。「Level 3の方が良い」ではなく、何がどう良いかを書く
