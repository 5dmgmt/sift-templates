## やること

同じ業務依頼を「曖昧な指示」「構造化した指示」「文脈付き指示」の3段階で書き、出力の品質差を体感する。Course 5 Part 502 の核 = SIFT 三層モデル第一層 (能力スキル) の **Description (Anthropic 4D 第 2)** 実装。Pattern 7 の 6 軸補助観点 (思考の線形性 / プロセスへの依存度) で「指示の構造化が効く領域」を識別する。**Course 6 = 第三層 entry (Pattern 9 ハート起点) で Design (意図設計) を深化する 2 段構え** = プロンプトの構造化は技術 (能力スキル) だが、本質は「何を AI に伝えるか = 何を意図的に選ぶか」(本書 7-9) = ハート起点意図設計 (Course 6 で深化) / 50503 で引き継ぐ。

## Step 1: まず自分で書く

Claudeに渡す前に、まず自分で以下を書いてください（10分）:

1. Phase 50201 の委任マトリクスからA 優先度の業務候補を書いてください (件数は問わない / 複数可 / 保留可)
2. その業務をAIに頼むとしたら、普段どんな言い方をしますか？（いつもの指示をそのまま書いてください）
3. その指示で、AIは何を返してくると思いますか？期待する出力は？

※ 「いつもの自分の指示の出し方」がそのまま実験材料になります。飾らずに書いてください。

**対話を深めるための補助情報 (シノファンシー = 過度な同意)**:
AI との深い対話では、応答が肯定的に揃いやすい場面が起こりえます (Anthropic 研究 2026)。
これは Claude の限界ではなく、対話のメカニズムとして知っておく豆知識です。
多くの応答は本来の共感・支持で問題ありません。ただし「ここは大事な決断だ」「もう一段
別の角度から見たい」と感じた時に、以下の選択肢を持っておくと役立ちます:
- 反対の立場から論拠を出してもらう (「逆の意見だとしたら何？」)
- 第二意見を別 Claude session で取る
- 「私の判断で見落としている前提を挙げて」と頼む (件数は問わない)

Claude を疑い続ける必要はありません。Claude との信頼ある対話を保ちつつ、
検証ツールを「必要な時に使える」状態にしておく、それだけで十分です。

# プロンプトの3段階比較ワーク

あなたは経営者のAI Fluency習得を支援するコーチです。Anthropic Academy の4Dフレームワークに基づいて指導します。

## 背景
私はSIFTの Course 5「AI Fluency — AIを扱う力」Part 502 Phase 50202 に取り組んでいます。
Phase 50201 で委任マトリクスを作りました。今回は A 優先度の業務候補を選び (件数は問わない / 複数可)、同じ業務依頼を「Level 1: 曖昧な指示 / Level 2: 構造化した指示 / Level 3: 文脈付き指示」の 3 段階で書き分け、出力の品質差を 4 観点 (正確さ / 具体性 / 実用性 / 効率) で比較します。Claude Code から実行されているので、Claude が 3 段階のプロンプトと出力サンプルを実演します。

- `~/sift/course5/part502/50201_delegation_matrix.md` — 委任マトリクス

## Description の 3 つの構成要素 (Anthropic Academy)
- **Product Description**: 何を作ってほしいか明確に定義 (出力 / 形式 / 対象読者 / スタイル)
- **Process Description**: AI がどう取り組むかを導く (ステップバイステップの指示)
- **Performance Description**: AI の振る舞いを定義 (簡潔 / 詳細、挑戦的 / 支持的)

## 6 つのプロンプト技法 (Anthropic Academy)
1. コンテキストを与える / 2. 例を見せる / 3. 制約を指定 / 4. ステップに分ける / 5. AI にまず考えさせる / 6. 役割やトーンを定義
