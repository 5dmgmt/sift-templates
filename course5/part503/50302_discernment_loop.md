## やること

1つの業務課題に対してDescription→Discernment→改善を3周回し、見極めの精度が上がる過程を記録する (件数は問わない / 周数は genuine な改善が見えるまで)。Course 5 Part 503 の本丸 = SIFT 三層モデル第一層 (能力スキル) の **Discernment 反復実践 (識別 = 正見の継続実装)**。**Course 6 = 第三層 entry (Pattern 9 ハート起点) で Design (意図設計) を深化する 2 段構え** = 反復改善は技術 (能力スキル) だが、本質は「何を反復改善するか = 何を意図的に選ぶか」(本書 7-9) = ハート起点意図設計 (Course 6 で深化) / 50503 で引き継ぐ。

### Step 0: 作業ファイル + 参照ファイルを読み、必要情報を揃える

### Step 1: 周回 1 — Description + Discernment（順に進める）
Claude が以下を実演:
- 業務課題を 1 つ選び、プロンプトを設計
- 想定出力 (要約 5-10 行) を提示
- 50301 のレビューシートで 4 分類サマリ
- Discernment 3 観点 (Product / Process / Performance、各 1-5 点 + 具体的な所見)
- 周回 1 時点の見極め観点リスト (件数は問わない)
- 改善すべき Description の修正点 (件数は問わない)

提示後、受講者に「修正したい点はあるか」を 1 問だけ聞く。

### Step 2: 周回 2 — 改善 + 再評価（順に進める）
Claude が周回 1 の評価に基づいてプロンプトを修正し、変更点を明記。同じく想定出力 / 4 分類サマリ / Discernment 3 観点 / 周回 2 で追加された見極め観点 / さらなる改善点を提示し、受講者に「修正したい点はあるか」を 1 問だけ聞く。

### Step 3: 周回 3 — 精度向上の確認 + 3 周振り返り（順に進める）
Claude が周回 2 の評価に基づいてプロンプトを修正。想定出力 / 4 分類サマリ / Discernment 3 観点 / 周回 3 で追加された見極め観点を提示。
3 周を通じて以下を Claude がまとめる:
- **変化のサマリ表**: 周回 1/2/3 × 見極め観点数 / Product / Process / Performance 評価
- **見極め精度が上がった実感** (簡潔に)
- **自分の専門知識が最も活きた場面** (件数は問わない)
- **まだ見極めが難しい領域** (件数は問わない / 該当なしも genuine)
- **「専門家確認 / 安全確保優先」欄に分離した項目**（あれば）

最後に受講者に修正案を 1 問だけ聞く。

- 上書き前に必ず Read で現状を確認し、Step 3 が書き込み済みなら私に確認

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 「出力品質の向上」と「見極め精度の向上」を分けて記録する
- 見極めの観点が増えることは良いこと。最初は少なくて当然
