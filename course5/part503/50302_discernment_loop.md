## 背景
私はSIFTのCourse 5「AI Fluency — AIを扱う力」Part 503「見極める力」に取り組んでいます。
このPhaseでは、Description-Discernment ループを3周回し、見極めの精度を体感的に高めます。

### Description-Discernment ループ（再掲）
1. 明確に記述する（Product + Process + Performance）
2. 品質を見極める（Product + Process + Performance）
3. 見極めに基づいて改善する
4. 自分の専門知識と判断を統合する

### 見極めの3観点
- **Product Discernment**: 出力の内容は正確か、適切か、一貫しているか
- **Process Discernment**: AIの推論プロセスに論理エラーや飛躍がないか
- **Performance Discernment**: AIの応答スタイルが目的に合っているか

## やってほしいこと

### 周回1: Description + Discernment
1. 業務課題を1つ選び、プロンプトを書いて実行
2. 出力を Phase 50301 のレビューシートで分類
3. Discernment の3観点（Product/Process/Performance）で評価
4. 改善すべきDescription（プロンプト）の修正点を特定

### 周回2: 改善 + 再評価
1. 周回1の評価に基づいてプロンプトを修正して再実行
2. 同じ方法で出力をレビュー・評価
3. 周回1→2で「見極めの観点」自体が増えたかを記録
4. さらなる改善点を特定

### 周回3: 精度向上の確認
1. 周回2の評価に基づいてプロンプトを修正して再実行
2. 同じ方法で出力をレビュー・評価
3. 3周を通じて「見極めの観点数」がどう変化したかをまとめる
4. 出力品質と見極め精度の両方の変化を記録

### 全体の振り返り
- 見極めの観点は何個増えたか
- 最も精度が上がった観点はどれか
- 自分の専門知識が最も活きた場面はどこか

## ルール
- 根拠がある部分と、推測の部分を分けて出力してください
- まだ確定していない暫定判断には【仮説】マークをつけてください
- 「出力品質の向上」と「見極め精度の向上」を分けて記録してください
- 見極めの観点が増えることは良いこと。最初は少なくて当然です
