## やること

1つの業務課題に対してDescription→Discernment→改善を周回し、見極めの精度が上がる過程を記録する (件数は問わない / 周数は genuine な改善が見えるまで)。Course 5 Part 503 の本丸 = SIFT 三層モデル第一層 (能力スキル) の **Discernment 反復実践 (識別 = 正見の継続実装)**。**Course 6 = 第三層 entry (Pattern 9 ハート起点) で Design (意図設計) を深化する 2 段構え** = 反復改善は技術 (能力スキル) だが、本質は「何を反復改善するか = 何を意図的に選ぶか」(本書 7-9) = ハート起点意図設計 (Course 6 で深化) / 50503 で引き継ぐ。

### Step 1: 初回周回 — Description + Discernment（順に進める）
Claude が以下を実演:
- 業務課題を 1 つ選び、プロンプトを設計
- 想定出力 (必要十分な要約 / 行数は問わない) を提示
- 50301 のレビューシートで 4 分類サマリ
- Discernment 3 観点 (Product / Process / Performance、各 1-5 点 + 具体的な所見)
- 初回周回時点の見極め観点リスト (件数は問わない)
- 改善すべき Description の修正点 (件数は問わない)

提示後、受講者に「修正したい点はあるか」を 1 問だけ聞く。

### Step 2: 改善周回 — 改善 + 再評価（順に進める / 周数は genuine な改善が見えるまで反復）
Claude が前周回の評価に基づいてプロンプトを修正し、変更点を明記。同じく想定出力 / 4 分類サマリ / Discernment 3 観点 / 当該周回で追加された見極め観点 / さらなる改善点を提示し、受講者に「修正したい点はあるか」を 1 問だけ聞く。「genuine な改善が見えなくなった / 観点が増えなくなった」と判断できる周回まで反復 (件数は問わない)。

### Step 3: 振り返り — 精度向上の確認（順に進める）
Claude が以下をまとめる:
- **変化のサマリ表**: 各周回 × 見極め観点の変化（増減 / 統合 / 深まり / 不足 / 変化なし）/ Product / Process / Performance 評価 (件数は問わない / 周数は genuine な改善が見えるまで)
- **見極め精度が上がった実感** (簡潔に)
- **自分の専門知識が最も活きた場面** (件数は問わない)
- **まだ見極めが難しい領域** (件数は問わない / 該当なしも genuine)
- **「専門家確認 / 安全確保優先」欄に分離した項目**（あれば）
- **損徳得厄メモ** (任意 / 該当なしも genuine / 本書 7-5 / 7-6): 見極め判断の補助観点として「短期得 (頭で得を追う) を選んだ理由か / 長期徳 (ハートで愛を出す) を選んだ理由か」を任意で記録

最後に受講者に修正案を 1 問だけ聞く。

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**（Step 0 の事前メモ未記入時の 3 問まとめ提示は唯一の例外 / Step 1-4 では厳守）。複数選択肢の提示や複数項目の同時質問は禁止
