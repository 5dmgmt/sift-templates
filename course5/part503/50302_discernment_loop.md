## やること

業務課題に対して Description→Discernment→改善を周回 (件数は問わない / 複数可)し、見極めの精度が上がる過程を記録する (件数は問わない / 周数は genuine な改善が見えるまで)。Course 5 Part 503 の本丸 = SIFT 三層モデル第一層 (能力スキル) の **Discernment 反復実践 (識別 = 正見の継続実装)**。**Course 6 = 第三層 entry (Pattern 9 ハート起点) で Design (意図設計) を深化する 2 段構え** = 反復改善は技術 (能力スキル) だが、本質は「何を反復改善するか = 何を意図的に選ぶか」(本書 7-9) = ハート起点意図設計 (Course 6 で深化) / 50503 で引き継ぐ。

## Step 1: まず自分で書く

Claudeに渡す前に、まず自分で以下を書いてください（10分 / 該当する問いを必要に応じて記述 / 件数は問わない）:

- Phase 50301 のレビューで、推測や要確認が目立った / 印象に残った業務 (複数可 / 該当なしも genuine)
- その業務で、AIの出力のどこを重点的にチェックすべきだと思いますか？
- 自分の専門知識で「これは確実に判断できる」という領域はどこですか？

※ 見極めは「全部自分で確認する」ことではなく、「どこを重点的に見るか」を決めることです。

**対話を深めるための補助情報 (シノファンシー = 過度な同意)**:
AI との深い対話では、応答が肯定的に揃いやすい場面が起こりえます (Anthropic 研究 2026)。
これは Claude の限界ではなく、対話のメカニズムとして知っておく豆知識です。
多くの応答は本来の共感・支持で問題ありません。ただし「ここは大事な決断だ」「もう一段
別の角度から見たい」と感じた時に、以下の選択肢を持っておくと役立ちます:
- 反対の立場から論拠を出してもらう (「逆の意見だとしたら何？」)
- 第二意見を別 Claude session で取る
- 「私の判断で見落としている前提を挙げて」と頼む (件数は問わない)

Claude を疑い続ける必要はありません。Claude との信頼ある対話を保ちつつ、
検証ツールを「必要な時に使える」状態にしておく、それだけで十分です。

### Step 1: 初回周回 — Description + Discernment（順に進める）

### Step 2: 改善周回 — 改善 + 再評価（順に進める / 周数は genuine な改善が見えるまで反復）

### Step 3: 振り返り — 精度向上の確認（順に進める）
Claude が以下をまとめる:
- **変化のサマリ表**: 各周回 × 見極め観点の変化（増減 / 統合 / 深まり / 不足 / 変化なし）/ Product / Process / Performance 評価 (件数は問わない / 周数は genuine な改善が見えるまで)
- **見極め精度が上がった実感** (簡潔に)
- **自分の専門知識が活きた場面 (件数は問わない / 該当なしも genuine)** (件数は問わない)
- **まだ見極めが難しい領域** (件数は問わない / 該当なしも genuine)
- **「専門家確認 / 安全確保優先」欄に分離した項目**（あれば）
- **損徳得厄メモ** (任意 / 該当なしも genuine / 本書 7-5 / 7-6): 見極め判断の補助観点として「短期得 (頭で得を追う) を選んだ理由か / 長期徳 (ハートで愛を出す) を選んだ理由か」を任意で記録
