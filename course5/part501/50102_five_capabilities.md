**三層モデル上の位置付け**: SIFT 三層モデルの **第一層 (能力スキル) と第三層 (ハート起点の意図設計) を統合する地点**。4D の中に閉じている限り「能力を持つ存在」のまま (本書全体の核警告)。Design = 第三層 (ハート) に立ってから始まる「意図設計」(本書 6-6 / 7-9)。**順序推奨**: Course 4 (Part 401-405) を先に受けてから本 Phase に進むと第二層 (起源を持つ不安) の歪みが緩和されている状態で 4D を評価できる。Course 6 (ハートを耕す) 未受講なら Design は「現時点の仮置き」で OK (Course 6 / 7 で再評価)。

## 三層モデル上の位置付け (Phase 50102 = 4D + Design の理論的核 / 詳細は `SIFT-LAYER-FRAMEWORK-RUNBOOK.md` §5)

このワークは SIFT 三層モデルの **「第一層 (能力スキル) と第三層 (ハート起点の意図設計) を統合する地点」** として位置付けられます。

### 4D = 第一層 (能力スキル / Anthropic AI Fluency framework)

| Capability | 内容 | 三層対応 + 6 軸 (Pattern 7) との関連 |
|---|---|---|
| Delegation 委任 | AI と人間の仕事分担 | 主に第一層 / 6 軸 B (価値生成の主体) + A (環境変化の時間軸) |
| Description 記述 | AI と効果的にコミュニケーション | 主に第一層 / 6 軸 C (思考の線形性) + E (プロセスへの依存度) |
| Discernment 見極め | AI 出力を批判的に評価 | 主に第一層 / 6 軸 D (専門性の方向性) + F (評価軸の単位) / 識別 = 本書 3-9 の正見と整合 |
| Diligence 勤勉さ | 責任ある AI 活用 | 主に第一層 / 6 軸 E (プロセスへの依存度) + F (評価軸の単位 = 個人 + AI ガバナンス) / 倫理判断要素は第二層 (起源を持つ不安) に近い |

→ 4D の中に閉じている限り、受講者は **「能力を持つ存在」のまま**。技術スキルとしては完成するが、「何のために能力を発揮するか」(意図) が問われない。

### Design = 第三層 (ハート起点の意図設計 / SIFT オリジナル / 4D の外)

> **「4D の外が AI Fluency の要であり、五次元経営に直結するところ」** (望月貴生, 2026-05-02)

Design は **表面上は技術 (ワークフロー設計)** だが、本質は:

1. **第二層の不安解消だけでは始まらない** — 第二層を緩めただけの Design は「思考停止後のジャッジ」(本書 3-5) を再生産する
2. **第三層 (ハート) に立ってから始まる「意図設計」** — 詳細は本書 6-6 (Course 6 で本格化 / 本 Phase では予告のみ)
3. **「能力を持つ存在 → 意図を選ぶ存在」への移行が起きる場所** — 4D は「能力」、Design は「意図」、何を仕組み化するか = 何を意図的に選ぶか
4. **「個人がご機嫌で生きる力」(40102 #40) の実装地点** (本書主旋律 / 深層概念は Course 6 / 7 で本格化)

→ **Anthropic 4D に Design を追加した SIFT の判断は、第三層に立ってからの意図設計の必要性で正当化される**。これが Anthropic 教材を超える AIFCC オリジナルの貢献。

### 五次元経営 (5dmgmt) との直結

5dmgmt = 五次元経営の「五次元」が、SIFT 5D の Design = 第三層 (ハート) からの意図設計と符合します。これは AIFCC のブランド哲学が「同じ構造を見ている」ことの主観的解釈であり、書籍シラバスでも一貫した世界観として確立されています。

### 順序ガイダンス

- **Course 4 (Part 401-405) 未受講の場合**: 第二層 (起源を持つ不安) が言語化されていない状態で 4D の評価をすると、不安駆動の動機で能力評価が歪みやすい。Course 4 を先に受けることを推奨します。
- **Course 6 (ハートを耕す) 未受講の場合**: Design を「単なるワークフロー設計」として評価すると、第一層の延長になります。Design の評価は「ハート起点の意図設計ができているか」を Course 6 完了後に再評価することを推奨します。本 Phase では「現時点での Design 観」を仮置きで記録し、Course 6 / 7 で再訪する前提で OK です。

## 5 つの能力 (4D + Design / 三層モデル明示)

**1. Delegation（委任）** = 第一層 — AIと人間の仕事分担を決める力
- Problem Awareness / Platform Awareness / Task Delegation
- 6 軸 B (価値生成の主体) + A (環境変化の時間軸) で補強

**2. Description（記述）** = 第一層 — AIと効果的にコミュニケーションする力
- Product / Process / Performance Description
- 6 軸 C (思考の線形性) + E (プロセスへの依存度) で補強

**3. Discernment（見極め）** = 第一層 — AI出力を批判的に評価する力
- Product / Process / Performance Discernment
- 6 軸 D (専門性の方向性) + F (評価軸の単位) / 識別 (本書 3-9 の正見) と整合

**4. Diligence（勤勉さ）** = 第一層 — 責任あるAI活用を確保する力
- Creation / Transparency / Deployment Diligence
- 6 軸 E (プロセスへの依存度) + F (評価軸の単位 = 個人 + AI ガバナンス) で補強
- 倫理判断要素は第二層 (起源を持つ不安) に近い

**5. Design（仕組みの設計）** = **第三層 (ハート起点の意図設計)** / SIFTオリジナル / 4D の外
- 表面: ワークフロー設計 / 文脈管理 / 改善サイクル
- **本質: 「能力を持つ存在」(4D) → 「意図を選ぶ存在」(Design) への移行地点**
- 「何を仕組み化するか = 何を意図的に選ぶか」(本書 7-9)
- 第二層の不安解消だけでは Design は始まらない (思考停止後のジャッジを再生産する / 本書 3-5)
- 第三層 = ハート起点の意図設計が立ち上がる地点 = 五次元経営 (5dmgmt) のブランド哲学と直結
- Course 6 (ハートを耕す) / Course 7 (整える・作る・回す) で本格的に深化する
