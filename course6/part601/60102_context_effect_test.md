### Step 1: 業務課題を 1 件選ぶ
Claude が業務候補を 1〜3 件提示し、受講者に「どれを実験対象にするか」を 1 問だけ聞く (60101 と同じでも別でも可)。

### Step 2: 3 条件で実演（1 ターン 1 条件）
Claude が同じプロンプトに以下 3 種類の文脈を渡した条件で、1 ターンに 1 条件ずつ想定出力を提示し、受講者に「修正したい点はあるか」を 1 問だけ聞く:
- **条件 A**: 自分の基本情報だけ (事業概要 / 役職 / 業界)
- **条件 B**: 条件 A + 業務固有の文脈 (過去の成果物 / 業務手順 / 対象者の情報)
- **条件 C**: 条件 B + 自己理解の文脈 (Course 1-5 から価値観 / 得意・苦手 / 意思決定スタイル)

### Step 3: 比較表 + コンテクスト効果マップ
Claude が以下を提示する:
- **3 条件比較表**: 4 観点 (的確さ / 具体性 / トーンの適切さ / そのまま使えるか) × 条件 A/B/C
- **A → B で変わった点** (業務文脈の効果): 件数は問わない / 該当なしも genuine
- **B → C で変わった点** (自己理解文脈の効果): 件数は問わない / 該当なしも genuine
- **コンテクスト効果マップ**: 文脈の種類 × 効果が出た観点 × 効果の大きさ (件数は問わない)
- **効果が大きかった文脈候補の種類**: (件数は問わない / 複数可) + 理由
- **文脈を増やしても変わらなかった部分**: 件数は問わない / 該当なしも genuine
- **文脈が逆効果になった点 (failure_log)**: 件数は問わない / 該当なしも genuine

最後に受講者に修正案を 1 問だけ聞く。
