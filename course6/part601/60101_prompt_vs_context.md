## やること

同じ業務課題を「プロンプトだけ」と「プロンプト+文脈ファイル」の2条件で実行し、出力品質の差を体感する。Course 6 全体は SIFT 三層モデル (第一層 = 4D 能力 / 第二層 = 4 不安 / 第三層 = ハート起点) のうち第三層 entry を扱う。Course 4 でアンラーンした第二層の土台から第一層の能力を組み直し、AI と共に「整える」運用に移る体験コース。Course 5 で立ち上げた 5 能力 (4D + Design = ハート起点意図設計) を、文脈を渡しながら AI と共同編集する形で使いこなす。Context は意図の置き場 / 意図はハート起点 (胸への意識 + 寝息の呼吸)。Course 7 で Workshop / RUN へ接続する準備期間。

## Step 1: まず自分で書く

Claudeに渡す前に、まず自分で以下を書いてください（10分）:

1. 「プロンプト」と「文脈」の違いを自分の言葉で説明すると？
2. 普段Claudeに依頼するとき、背景情報をどの程度伝えている？
3. Claudeの出力に「的外れ」を感じたことはある？ どんな場面？
4. 自社の業務で「AIに文脈を渡したら精度が上がりそう」と思うものは？

※ 正解はありません。今の感覚で書いてください。この事前メモが比較実験の出発点になります。

**対話を深めるための補助情報 (シノファンシー = 過度な同意)**:
AIは、会話の流れによって同意寄りの応答を返すことがあります。
重要な判断では、反対意見、別セッション、一次資料も参考にし、最終判断はご自身で行ってください。
多くの応答は本来の共感・支持で問題ありません。ただし「ここは大事な決断だ」「もう一段
別の角度から見たい」と感じた時に、以下の選択肢を持っておくと役立ちます:
- 反対の立場から論拠を出してもらう (「逆の意見だとしたら何？」)
- 第二意見は、Claude にサブエージェントで取ってもらいます
- 「私の判断で見落としている前提を 3 つ挙げて」と頼む
Claude を疑い続ける必要はありません。Claude との信頼ある対話を保ちつつ、
検証ツールを「必要な時に使える」状態にしておく、それだけで十分です。

# プロンプトだけ vs 文脈を渡す — 比較実験

> **この枠組みの扱い方**: 三層・4不安・損徳得厄・ハートは、本人の実感に合う場合だけ使う任意の見取り図です。深い・浅い、良い・悪い、能力の優劣を付けず、当てはまらない・保留も同じ重さで扱います。損得、価値、安全、関係者への影響、身体感覚を並べ、確認できる根拠と本人の実感を合わせて判断します。

### Step 2: 条件 A — プロンプトだけで実行（1 ターン / **文脈非汚染厳守**）
