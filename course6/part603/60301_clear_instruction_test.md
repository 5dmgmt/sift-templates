# 指示と期待の明確化

### Step 1: 頻出業務を選定 (件数は問わない / 複数可 / 該当なしも genuine)
Claude が事前メモと 60203 の改善プロンプト候補から、以下 3 条件を満たす業務 (件数は問わない / 複数可) を提示する:
- 毎週または毎月やっている
- AI に依頼する頻度が高い (または高くしたい)
- 出力の「良し悪し」を自分で判断できる

提示後、受講者に「この件数で進めるか / 修正したい点はあるか」を 1 問だけ聞く。

### Step 2: 4 項目の明文化（1 ターン 1 業務）
各業務について (件数は問わない)、Claude が 1 ターンに 1 業務ずつ以下 4 項目を提示し、受講者に「修正したい点はあるか」を 1 問だけ聞く:
- **やってほしいこと**: 具体的なアクション (動詞で始める)
- **期待する出力形式**: Markdown / 表 / 箇条書き / 文章など、具体的なフォーマット
- **禁止事項**: やってほしくないこと、使ってほしくない表現
- **成功条件**: この出力なら合格、という基準

### Step 3: Claude が各プロンプト (件数は問わない)を実演 + 結果記録
Claude が作成した各プロンプト (件数は問わない) それぞれに対して、想定出力 (要約 5-10 行) と評価を提示する:
- 成功条件を満たしたか (Yes / No)
- 良かった点 / 改善が必要な点

最後に「明確化で最も効果が大きかった項目」「各業務に共通する (件数は問わない)プロンプトの弱点」「Phase 60302 で構造化すべきプロンプト」を Claude が提示し、受講者に修正案を 1 問だけ聞く。

### Step 4: 成果物を vault に書き戻す
`~/sift/course6/part603/60301_clear_instruction_test.md` の Step 3「成果物」セクションを Edit で書き込む。

- チェックリストの該当項目に ✓ を入れる
- 上書き前に必ず Read で現状を確認し、Step 3 が書き込み済みなら私に確認

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 1 回目で完璧なプロンプトは書けない。「改善の余地」を見つけることが目的
