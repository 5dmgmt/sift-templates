### Step 0: 作業ファイル + 参照ファイルを読み、必要情報を揃える
1. **作業ファイル** `~/sift/course6/part602/60202_vault_restructure.md` を Read で開き、Step 1 セクションの事前メモを取得
2. **参照ファイル** `~/sift/course6/part602/60201_context_inventory.md` を Read で開く。Step 3 が空欄 or テンプレのままの場合、ここで停止して受講者に「Phase 60201 を先に完遂してください」と伝える
3. 事前メモが空欄なら、以下 4 問をまとめて 1 度に提示し、私の答えを待つ（A/B/C 選択肢は出さない）:
   - 今の Obsidian vault のフォルダ構成は (ざっくりで OK)

4. 必要情報が揃ったら確認や進め方ヒアリングをはさまず即 Step 1 へ

### Step 1: 5 フォルダ構成を設計（1 ターン 1 フォルダ）
Claude が以下 5 フォルダを基本に、60201 の棚卸し結果からファイルを 1 ターンに 1 フォルダずつ配置して提示する。受講者に「修正したい点はあるか」を 1 問だけ聞く:
- **01_自己理解**: 人生年表 / 価値観 / 得意・苦手 / リーダーシップ OS
- **02_事業**: 事業パーパス / ビジネスモデル / 顧客像 / 市場環境
- **03_業務手順**: 委任マトリクス / 仕組み設計 / プロンプトテンプレート
- **04_AI 運用**: ガードレール / 停止条件 / 品質チェックリスト
- **05_振り返り**: 各 Course の統合メモ / 課題リスト / 成長ログ

各フォルダに配置 (件数は問わない)する。

### Step 2: 入口ノート (00_INDEX.md) の設計
Claude が 00_INDEX.md の構成 (5 フォルダの概要 + 各フォルダ内の主要ファイルへのリンク) を Markdown で完成形を提示する。受講者は Obsidian にコピーすれば動く状態。

### Step 3: ファイル移動手順 + archive 退避
Claude がファイル移動の実行手順チェックリストを提示する:
- 各フォルダへの移動手順 (Obsidian のリネーム機能で リンクを保つ)
- archive フォルダへの退避対象 (60201 で「不要」分類したもの、削除しない)
- 入口ノートのリンクが全て通ることを確認

最後に「Phase 60203 で Claude に読ませるときの注意点」を Claude が提示 (件数は問わない / 該当なしも genuine)し、受講者に修正案を 1 問だけ聞く。

### Step 4: 成果物を vault に書き戻す
受講者が Obsidian でファイル移動を完了したら、`~/sift/course6/part602/60202_vault_restructure.md` の Step 3「成果物」セクションを Edit で書き込む。
- ファイルの Step 1 / Step 2 (このプロンプト) は触らない
- Step 3 の 5 フォルダ構成 / 入口ノート構成 / 移動手順チェックリスト / 次の Phase へのメモ を埋める
- チェックリストの該当項目に ✓ を入れる
- 上書き前に必ず Read で現状を確認し、Step 3 が書き込み済みなら私に確認

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 完璧な構成を目指さず、「まず動く状態」を優先する
- 「不要」分類は archive 退避のみ。削除しない
