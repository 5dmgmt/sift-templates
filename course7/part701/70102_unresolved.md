## 進め方（私に確認を取らずに開始してください）

### Step 0: 作業ファイル + 参照ファイルを読み、必要情報を揃える
1. **作業ファイル** `~/sift/course7/part701/70102_unresolved.md` を Read で開き、Step 1 セクションの事前メモを取得
2. **参照ファイル** `~/sift/course7/part701/70101_sift_retrospective.md` を Read で開く。Step 3 が空欄 or テンプレのままの場合、ここで停止して受講者に「Phase 70101 を先に完遂してください」と伝える
3. 事前メモが空欄なら、以下 4 問をまとめて 1 度に提示し、私の答えを待つ（A/B/C 選択肢は出さない）:

   - 途中で方針を変えたものは？ なぜ変えたか

4. 必要情報が揃ったら確認や進め方ヒアリングをはさまず即 Step 1 へ

### Step 1: 4 観点で未解決事項を洗い出す（1 ターン 1 観点）
Claude が 1 ターンに 1 観点ずつ、未解決事項を表形式で提示し、受講者に「修正したい点はあるか」を 1 問だけ聞く:
- **未完了の成果物**: 作りかけ / 更新が必要なもの (Phase 番号 + 未完了の理由 + 緊急度)
- **未回答の問い**: SIFT で問いかけたが答えが出ていないもの (出た Phase + 未回答の理由)
- **仮説のまま**: 【仮説】マークが付いたまま検証していないもの (Phase + 検証方法)
- **方針変更**: 途中で方向転換し、元の方針が放置されているもの (元の方針 + 変更後 + 放置部分)

### Step 2: 各項目に優先度・次のアクション
各未解決事項に以下の情報を Claude が付ける:
- **なぜ未解決か**: 時間不足 / 情報不足 / 判断保留 / 優先度低
- **次にどうするか**: Workshop 内で解決 / SIFT 成果物の更新で解決 / 保留のまま
- **緊急度**: すぐ必要 / あった方が良い / なくても進める

### Step 3: Workshop で取り組む 3 件を選定
Claude が未解決事項から Workshop で優先的に取り組む 3 件を選び、選定理由 + 期待する成果を提示する。
最後に「Phase 70103 で統括メモに含めるべきこと」を 2〜3 件 Claude が提示し、受講者に修正案を 1 問だけ聞く。

### Step 4: 成果物を vault に書き戻す
`~/sift/course7/part701/70102_unresolved.md` の Step 3「成果物」セクションを Edit で書き込む。
- ファイルの Step 1 / Step 2 (このプロンプト) は触らない
- Step 3 の 4 観点別未解決事項リスト / Workshop で取り組む 3 件 / 次の Phase へのメモ を埋める
- チェックリストの該当項目に ✓ を入れる
- 上書き前に必ず Read で現状を確認し、Step 3 が書き込み済みなら私に確認

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 「全部解決しなければ」と思わなくて OK。優先度をつけることが目的
