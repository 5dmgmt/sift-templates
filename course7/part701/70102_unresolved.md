## やること

SIFT全体で未解決の課題・疑問・未完了事項を洗い出し (件数は問わない)、「なぜ未解決か」「次にどうするか」を整理する。Course 7 SIFT 三層モデル統合フェーズの一環。**残存項目を 3 層に分類**: 第一層 (4D 能力スキルとして再構築 = Anthropic 4D) / 第二層 (動機転換対象 = 4 不安 / Course 4 で言語化済 → Workshop/RUN で継続運用) / 第三層 (ハート entry 必要 = Design 概念 + ハート起点 = 胸への意識 + 寝息の呼吸 / Course 5-6 で導入済 → Workshop/RUN で継続運用)。

## Step 1: まず自分で書く

Claudeに渡す前に、まず自分で以下を書いてください（10分）:

1. SIFTで「やり残した」と感じることは？
2. 答えが出ていない問いはある？
3. 途中で方針を変えたものは？ なぜ変えた？
4. Workshopで解決したいと思っている課題は？

※ 未解決＝失敗ではありません。「次に取り組むべき優先課題」を明確にする作業です。

**対話を深めるための補助情報 (シノファンシー = 過度な同意)**:
AIは、会話の流れによって同意寄りの応答を返すことがあります。
重要な判断では、反対意見、別セッション、一次資料も参考にし、最終判断はご自身で行ってください。
多くの応答は本来の共感・支持で問題ありません。ただし「ここは大事な決断だ」「もう一段
別の角度から見たい」と感じた時に、以下の選択肢を持っておくと役立ちます:
- 反対の立場から論拠を出してもらう (「逆の意見だとしたら何？」)
- 第二意見は、Claude にサブエージェントで取ってもらいます
- 「私の判断で見落としている前提を挙げて」と頼む (件数は問わない / 該当なしも本人の今の実感として扱う)
Claude を疑い続ける必要はありません。Claude との信頼ある対話を保ちつつ、
検証ツールを「必要な時に使える」状態にしておく、それだけで十分です。

### Step 1: 4 観点で未解決事項を洗い出す（1 ターン 1 観点 / 件数は問わない / 該当なしも本人の今の実感として扱う / 0 件でも完了）
Claude が 1 ターンに 1 観点ずつ、未解決事項を表形式で提示し、受講者に「修正したい点はあるか」を 1 問だけ聞く。**観点ごとに該当なしも本人の今の実感として扱う** (発見件数を稼ぐために無理に挙げない):
- **未完了の成果物**: 作りかけ / 更新が必要なもの (Phase 番号 + 未完了の理由 + 緊急度)
- **未回答の問い**: SIFT で問いかけたが答えが出ていないもの (出た Phase + 未回答の理由)
- **仮説のまま**: 【仮説】マークが付いたまま検証していないもの (Phase + 検証方法)
- **方針変更**: 途中で方向転換し、元の方針が放置されているもの (元の方針 + 変更後 + 放置部分)

### Step 2: 各項目に優先度・次のアクション・分類
各未解決事項に以下の情報を Claude が付ける:
- **なぜ未解決か**: 時間不足 / 情報不足 / 判断保留 / 優先度低 / 専門家確認 / 安全確保優先 / 権限不足 / 本番環境では扱わない / sandbox or test data 限定
- **次にどうするか**: Workshop 内で解決 / SIFT 成果物の更新で解決 / 保留のまま / 専門家へ相談 / 安全領域分離欄へ
- **緊急度**: すぐ必要 / あった方が良い / なくても進める

### Step 3: 残存項目を SIFT 三層モデルで 3 層分類 (核セクション)
Claude が未解決事項を以下 3 層に分類して提示する (件数は問わない / 該当なしも本人の今の実感として扱う):
- **第一層 (4D 能力スキルとして再構築 / Anthropic 4D = Delegation / Description / Discernment / Diligence)**: 技術的に対応可能な未解決事項 → Workshop で実装スキル化 (Design 概念は第三層、ここには含めない)
- **第二層 (動機転換対象 = 4 不安)**: 「やりたくない / 怖い」が背景にある未解決事項 → Course 4 で言語化済の 4 不安を Workshop / RUN で継続運用 / 言語化メソッド (IFS / Schema Therapy / Focusing / Cognitive Defusion / ジャーナリング) で扱う
- **意図や身体感覚を確かめる任意観点 (Design 概念 + ハート起点 = 胸への意識 + 寝息の呼吸)**: 論理だけでは決めにくい未解決事項について、身体感覚も判断材料の一つとして確かめる。損得、価値、安全、関係者への影響、確認できる根拠と並べて扱う

### Step 4: Workshop で取り組む対象を選定 + 安全領域分離
Claude が「Workshop で通常処理してよい」未解決事項から優先的に取り組む対象を選び (件数は問わない / 該当なしも本人の今の実感として扱う)、選定理由 + 期待する成果 + 三層モデル位置付けを提示する。専門家確認 / 安全確保優先 / 権限不足 / 本番扱い禁止 領域に該当するものは Workshop 候補から外し、安全領域分離欄に転記。
最後に「Phase 70103 で統括メモに含めるべきこと」を Claude が提示 (件数は問わない)、受講者に修正案を 1 問だけ聞く。

   - チェックリストの該当項目に ✓ を入れる

## ルール
- **本人の希望を優先**し、途中で保留・休止・別の問いへの変更を選べるようにする。答えたくない理由は求めない
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止 (Step 0-F の 4 問まとめ提示は唯一の例外)
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 引用は Phase ID + セクション名 + 要約のみ、生引用禁止
- 「全部解決しなければ」と思わなくて OK。優先度をつけることが目的
- 専門家確認 / 安全確保優先 / 権限不足 / 本番扱い禁止 領域は Workshop 候補から外す
- vault safety boundary / redact / 安全領域分離 / 競合更新検知のいずれかに違反する状況になったら、即停止して受講者に判断を仰ぐ
