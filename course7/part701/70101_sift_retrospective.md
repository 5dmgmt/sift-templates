## 進め方（私に確認を取らずに開始してください）

### Step 0: 作業ファイル + 参照ファイル 6 件 + Course 1-6 全成果物を確認
1. **作業ファイル** `~/sift/course7/part701/70101_sift_retrospective.md` を Read で開き、Step 1 セクションの事前メモを取得
2. **参照ファイル 6 件** をすべて Read で開く。いずれか 1 件でも Step 3 が空欄 or テンプレのままの場合、ここで停止して受講者に「該当 Course 振り返り Phase (10503 / 20503 / 30503 / 40503 / 50503 / 60503) のうち未完遂のものを先に完遂してください」と該当 Phase ID を明示して伝える
3. `~/sift/course1/` 〜 `~/sift/course6/` 配下の `.md` ファイル一覧を Glob で取得 (90 件以上)
4. 事前メモが空欄なら、以下 5 問をまとめて 1 度に提示し、私の答えを待つ（A/B/C 選択肢は出さない）:
   - SIFT プログラム全体で最も重要だったことを 3 行で
   - 自分が最も変わったと感じる点は？
   - 予想外の発見はあったか
   - SIFT を始める前の自分に一言アドバイスするなら？
   - Workshop で「これを作りたい」と今思っていることは？
5. 必要情報が揃ったら確認や進め方ヒアリングをはさまず即 Step 1 へ

### Step 1: 全成果物の一覧（Course 別、6 ターン）
Claude が 1 ターンに 1 Course ずつ、その Course の全成果物 (15 件 or 9 件) を Phase 番号 / ファイル名 / 内容要約 1 行 / 状態 (完了 / 更新が必要 / 未使用) の表形式で提示する。

### Step 2: 各 Course の最大の気づき 3 件（1 ターン 1 Course）
Claude が 1 ターンに 1 Course ずつ、6 件の参照ファイルを根拠に以下を提示し、受講者に「修正したい点はあるか」を 1 問だけ聞く:
- **気づき 1**: 最も大きな発見 (具体的な引用元付き)
- **気づき 2**: 予想外だったこと
- **気づき 3**: 今の自分に最も影響を与えていること

6 Course × 3 件 = 合計 18 件以上。

### Step 3: Course 間のつながり + 一貫した変化
Claude が 18 件の気づきを俯瞰し、以下を提示する:
- **Course 間でつながっているテーマ**: 3 件以上
- **一貫した変化**: 1〜2 件
- **矛盾や未解決の部分** (failure_log): 0〜2 件 (該当があれば)
- **Phase 70102 で深掘りする未解決事項**: 3〜5 件

最後に受講者に修正案を 1 問だけ聞く。

### Step 4: 成果物を vault に書き戻す
`~/sift/course7/part701/70101_sift_retrospective.md` の Step 3「成果物」セクションを Edit で書き込む。
- ファイルの Step 1 / Step 2 (このプロンプト) は触らない
- Step 3 の 6 Course 全成果物リスト / 各 Course の気づき 3 件 / Course 間のつながり / 次の Phase へのメモ を埋める
- チェックリストの該当項目に ✓ を入れる
- 上書き前に必ず Read で現状を確認し、Step 3 が書き込み済みなら私に確認

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 「きれいなまとめ」にせず、矛盾や未解決の部分もそのまま記録する
