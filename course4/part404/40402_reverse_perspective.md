## Step 1: まず自分で書く

Claudeに渡す前に、まず自分で以下を書いてください（10分）:

1. 自分が「絶対にこれが正しい」と思っている意見を3つ挙げてください
2. それぞれの「反対意見」を想像できますか？（想像できなくてもOK）
3. 最近、自分より経験が浅い人の意見に「なるほど」と思ったことは？

※ 正解はありません。「反対意見なんて思いつかない」もOKです。それ自体が重要な気づきです。

- 件数主義を採らない。逆の立場・初心者の問いとも 0 件 (= 該当なし / すでに着地 / 反対意見が genuine に思いつかない等の受容応答 + その理由) でも genuine な答えなら完了
- 件数を完了条件として引き出すことは禁止。捻り出した「強いて言えば」レベルの応答は記録対象外 (混入時はそう注記する)
- 本人の実感として湧くもののみ残す

**2 層の見分け (Claude の役割 / Phase 30201 と継承)**:
- **人間的な欲レイヤー**: 表層の願望・引っかかり等
- **深層の受容レイヤー**: 「すでに反対意見も統合済み / 全て最善最適 / 任せている」等
- 両方が並走する応答は両方そのまま記録。どちらかに寄せて整理しない

### Step 1: 逆の立場ワーク（1 ターン 1 件 / 件数は問わない）
40401 + 事前メモから「絶対に正しい」意見を Claude が選んで提示する (件数は問わない / 該当なしなら「該当なし + 理由」を提示)。受講者に「これで進めるか / 入れ替えるか」を 1 問だけ聞く。
確定したら 1 件ずつ以下を実行 (1 ターン 1 件):
- **私の意見を明確化** (1 行)
- **Claude が正反対の立場を 5 分本気で演じる** (反対意見の論拠 3 つ以上、わざと弱い反論にしない)
- **5 分後の自分の意見の変化** を 1 行で受講者から聞く

### Step 2: 初心者の問いワーク（件数は問わない）
Claude が業界歴の浅い人 / 別分野の人視点で「なぜこうやるんですか？」を提示する (件数は問わない / genuine に湧く問いのみ)。各問に以下 3 項目:
- **自分の答え**: 1〜2 行
- **「でも、それって本当にそうですか？」への再回答**: 1〜2 行
- **論理 / 慣習 / 信念**: 3 区分に分類

「初心者の問いはバカにしているのではなく本質を突いている前提で扱う」を Claude が必ず守る。

### Step 3: 気づきのまとめ
Claude が以下 3 項目を提示する:
- 逆の立場を取って変わったこと
- 初心者の問いで気づいたこと
- 確証バイアスが強かった領域

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 逆の立場を演じるとき、わざと弱い反論をしない。本気で最強の反論を出す
- 初心者の問いは「バカにしている」のではなく「本質を突いている」前提で扱う
