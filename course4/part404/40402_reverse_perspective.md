## やること

Phase 40401 で 特定された前提について、自分の意見と正反対の立場を 5 分だけ本気で考え (確証バイアス崩し)、さらに業界の初心者の視点から自分の前提を問い直す。「絶対正しい」と思っている意見の背後に、手放しにくさの理由が隠れていることがある点に注意 (件数は問わない)。

---

## Step 1: まず自分で書く

Claudeに渡す前に、まず自分で以下を書いてください（10分）:

1. 自分が「絶対にこれが正しい」と思っている意見を思いつく分だけ挙げてください (件数は問わない)
2. それぞれの「反対意見」を想像できますか？（想像できなくてもOK）
3. 最近、自分より経験が浅い人の意見に「なるほど」と思ったことは？

※ 正解はありません。件数も問いません。「反対意見なんて思いつかない」もOKです。それ自体が重要な気づきです。

**対話を深めるための補助情報 (シコファンシー = 過度な同意)**:
AIは、会話の流れによって同意寄りの応答を返すことがあります。
重要な判断では、反対意見、Claude のサブエージェントの意見、一次資料も参考にし、最終判断はご自身で行ってください。
多くの応答は本来の共感・支持で問題ありません。ただし「ここは大事な決断だ」「もう一段
別の角度から見たい」と感じた時に、以下の選択肢を持っておくと役立ちます:
- 反対の立場から論拠を出してもらう (「逆の意見だとしたら何？」)
- 第二意見は、Claude にサブエージェントで取ってもらいます
- 「私の判断で見落としている前提を挙げて」と頼む (件数は問わない)
Claude を疑い続ける必要はありません。Claude との信頼ある対話を保ちつつ、
検証ツールを「必要な時に使える」状態にしておく、それだけで十分です。

## 完了条件 (件数主義ではない)

- 件数主義を採らない。逆の立場・初心者の問いとも 0 件 (= 該当なし / すでに着地 / 反対意見が本人の実感に沿って思いつかない等の受容応答 + その理由) でも本人の今の実感に沿う答えなら完了
- 件数を完了条件として引き出すことは禁止。捻り出した「強いて言えば」レベルの応答は記録対象外 (混入時はそう注記する)
- 本人の実感として湧くもののみ残す

**応答の二重性の見分け (Claude の役割)**:
- **今も残る願い・違和感**: 願望・引っかかり等

- 両方が並走する応答は両方そのまま記録。どちらかに寄せて整理しない
- どちらも同じ重さの本人の言葉として扱い、深い・浅い、良い・悪いを付けない。

### Step 1: 逆の立場ワーク（件数は問わない / 順に進める）
40401 + 事前メモから「絶対に正しい」意見を Claude が選んで提示する (件数は問わない / 該当なしなら「該当なし + 理由」を提示)。受講者に「これで進めるか / 入れ替えるか」を 1 問だけ聞く。
確定したら順に以下を実行:
- **私の意見を明確化** (簡潔に)
- **Claude が正反対の立場を 5 分本気で演じる** (反対意見の論拠を 本気で出す / 件数は問わない / わざと弱い反論にしない / シコファンシー注意)
- **5 分後の自分の意見の変化** を簡潔に受講者から聞く
- **手放しにくさの理由の任意の振り返り** (オプション / Phase 40202-40203 で特定した 手放しにくさの理由と接続: 「絶対正しい」と思っていたのは 不安から選んでいたか? 該当なしも本人の今の実感として扱う / 「該当の有無」のみで自己ラベル化を避ける)

### Step 2: 初心者の問いワーク（件数は問わない）
Claude が業界歴の浅い人 / 別分野の人視点で「なぜこうやるんですか？」を提示する (件数は問わない / 本人の実感に沿って湧く問いのみ)。各問に以下 3 項目:
- **自分の答え** (簡潔に)
- **「でも、それって本当にそうですか？」への再回答** (簡潔に)
- **論理 / 慣習 / 信念**: カテゴリに分類

「初心者の問いはバカにしているのではなく本質を突いている前提で扱う」を Claude が必ず守る。

## ルール
- **本人の希望を優先**し、途中で保留・休止・別の問いへの変更を選べるようにする。答えたくない理由は求めない
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 逆の立場を演じるとき、わざと弱い反論をしない。本気で最強の反論を出す
- 初心者の問いは「バカにしている」のではなく「本質を突いている」前提で扱う
