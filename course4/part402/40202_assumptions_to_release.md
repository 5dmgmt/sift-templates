## 三層モデル上の位置付け (Phase 40202 = Pattern 6 全面適用 / 第二層動機転換対象選定の核 / 詳細は `SIFT-LAYER-FRAMEWORK-RUNBOOK.md` §3)

このワークは SIFT 三層モデルの **第二層 (起源を持つ不安) の 4 不安マッピング地点** です (= 第二層の分離保持は 40103 で完了済 / 本 Phase では分離済み動機転換対象を Pattern 6 4 不安として構造化):

### 第二層 4 不安 (Pattern 6 / 望月 note 記事 + 望月著書 1-3 深度 A)

| 不安 | 構造 | 起源 | 表れる前提例 |
|---|---|---|---|
| **存在価値不安** | 「アウトプットしないと自分の存在価値がない」 | 家系・幼少期・社会人初期の評価環境 | 成果(数字)で判断 / 経営者だから常時 ON |
| **無能露呈不安** | 「無能と見られたら居場所がなくなる」 | 評価社会 / 競争環境 / 「優秀でないと愛されない」家庭 | 一流のやり方 / 優秀第一原則 |
| **承認喪失不安** | 「重要他者からの評価を失うと存在が脅かされる」 | 家系・組織・業界 | 礼儀 / 期待に応える / 業界で一流認知 |
| **コントロール喪失不安** | 「状況を掌握しないと不安」「委ねられない」 | リスク管理職 / 経営者意識 / 過去のトラウマ | 経営者だから常時 ON / 権力非対称への構え |

→ **本 Phase の核**: 各「手放すべき前提」について、**背後にある 4 不安のどれが駆動しているか** を識別する (該当なし / 複数該当 / 不明も genuine な答え)。これが Phase 40203 (4 不安への対応分析 = 動機転換ワーク本丸) の入力情報になる。

### 第二層分離の重要原則

- **言語化のみ**: 本 Phase では 4 不安を「消す」「克服する」のではなく、**認識して中立化する** だけ。完全消去を目指すと別の不安 (失敗不安) を生む。
- **本人の実感優先**: 「該当しない / まだ言語化できない / 自分にはこの不安はない」も genuine な答え。Claude が「絶対あるはず」と捻り出さない。
- **第二層の言語化だけでは「思考停止しても、ジャッジは止まらない」(本書 3-5)**: 真の解除は第三層 (ハート / Course 6) で起きる。本 Phase は「動機転換の入口」であって到達点ではない。
