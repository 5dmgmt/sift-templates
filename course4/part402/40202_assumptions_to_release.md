## Step 1: まず自分で書く

Claudeに渡す前に、まず自分で以下を書いてください（10分）:

1. Phase 40201 の比較表を見て、「これは手放すべきだ」と思うものを思いつく分だけ挙げてください (件数は問わない)
2. その中で「頭では分かっているけど手放したくない」ものはどれですか？
3. 手放すことで「誰が困る」と思いますか？（自分、チーム、顧客、取引先...）

※ 正解はありません。件数も問いません。正直な気持ちを書いてください。「頭では分かっているけど手放したくない」感覚は、そのまま書いてください — Phase 40202/40203 で扱います。

**対話を深めるための補助情報 (シコファンシー = 過度な同意)**:
AIは、会話の流れによって同意寄りの応答を返すことがあります。
重要な判断では、反対意見、Claude のサブエージェントの意見、一次資料も参考にし、最終判断はご自身で行ってください。
多くの応答は本来の共感・支持で問題ありません。ただし「ここは大事な決断だ」「もう一段
別の角度から見たい」と感じた時に、以下の選択肢を持っておくと役立ちます:
- 反対の立場から論拠を出してもらう (「逆の意見だとしたら何？」)
- 第二意見は、Claude にサブエージェントで取ってもらいます
- 「私の判断で見落としている前提を挙げて」と頼む (件数は問わない)
Claude を疑い続ける必要はありません。Claude との信頼ある対話を保ちつつ、
検証ツールを「必要な時に使える」状態にしておく、それだけで十分です。

## 完了条件 (件数主義ではない)

- 件数主義を採らない。手放すべき前提 0 件 (= 該当なし / すでに手放し済み / 全て検証済) でも本人の今の実感に沿う答えなら完了
- 件数を完了条件として引き出すことは禁止。捻り出した「強いて言えば」レベルの応答は記録対象外 (混入時はそう注記する)
- 本人の実感として湧くもののみ残す

**応答の二重性の見分け (Claude の役割)**:
- **今も残る願い・違和感**: 願望・引っかかり等
- **受け入れられている実感**: 「すでに手放している / 全て最善最適 / 任せている」等
- 両方が並走する応答は両方そのまま記録。どちらかに寄せて整理しない
- どちらも同じ重さの本人の言葉として扱い、深い・浅い、良い・悪いを付けない。

### Step 1: 手放すべき前提を選ぶ
40201 の比較表と 40103 の手放しにくい前提一覧から、Claude が以下 3 基準を満たす「手放すべき前提」を選んで提示する (件数は問わない / 該当なしなら「該当なし + 理由」を提示):
- AI 後の代替手段が明確に存在する
- 維持するコスト (時間・エネルギー・機会費用) が高い
- 手放すことで新しい可能性が開ける

提示後、受講者に「入れ替えたい項目はあるか」を 1 問だけ聞く。

### Step 2: 各前提の影響を 5 項目で分析 (手放しにくさの理由を含む)
全件について、Claude がまとめて以下 5 項目を埋めた一覧表を提示する (件数は問わない):
- **手放したときのメリット**: 何が楽になるか / 可能になるか
- **手放したときのリスク**: 何を失うか / 悪化する可能性
- **影響範囲**: 自分 / チーム / 顧客 / 事業全体
- **移行難易度**: 低 / 中 / 高
- **手放しにくさの理由 (気持ちの面 / 該当なし・不明も可)**: 本人の言葉で記録。判定根拠 (= preWriting で「頭では分かっているけど手放したくない」と感じた感覚 / 40201 の「感情的に手放しにくいもの」メモ) も 1 行記録。

提示後、受講者に「修正したい項目はあるか」を 1 問だけ聞く。
最後に Claude が以下を提示する:
- **優先順位**: 「すぐ着手できる (低)」「準備が必要 (中)」「慎重 (高)」
- **「手放したくない前提 (正直に)」リスト**: 手放しにくさの理由が背後にあるものは特に明示
- **40203 への引き継ぎ**: 手放しにくさの理由マッピングで identified された前提は、Phase 40203 で書き出しの問いで動機の見直しを行う対象になる。「該当なし / まだ言語化できない」も本人の今の実感に沿う答え (Claude が無理やり 手放しにくさの理由に当てはめない / シコファンシー注意)。
