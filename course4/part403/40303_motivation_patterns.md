## 背景
私はSIFT Course 4「アンラーン -- 調和と創発へ」Phase 40303 に取り組んでいます。
前回の Phase 40302 で調和と創発を自分の言葉で定義しました。今回は自分の行動の動機パターンを挙げて「不安と恐怖」「愛と感謝」に仕分け、結果の違いを観察します (件数は問わない / Part 403 統合 Phase + 損徳得厄の法則の入口 / 本書 7-5 / 7-6)。
不安と恐怖を動機とする行動は **頭で得を追う = 短期得・長期厄** に向かい、愛と感謝を動機とする行動は **ハートで愛を出す = 短期損・長期徳** に向かう (本書 7-5 損徳得厄の法則)。どちらが「正しい」ではなく「どんな結果を生むか」を観察するのが目的。
このプロンプトは Claude Code から実行されています。Read / Edit ツールで vault のファイルを直接読み書きしてください。

## 三層モデル上の位置付け (Phase 40303 = Part 403 統合 / 損徳得厄の入口 / 第二層と第三層の接続地点 / 詳細は `SIFT-LAYER-FRAMEWORK-RUNBOOK.md` §4 + §7)

このワークは SIFT 三層モデルの **第二層 (起源を持つ不安) と第三層 (ハート起点意図設計) の接続地点** として位置付けられます:

### 損徳得厄の法則 (本書 7-5 / 7-6 / 経営判断の継続的判定軸)

| 動機 | 短期 | 長期 |
|---|---|---|
| **頭で得を追う** = 不安・恐怖駆動 = 第二層 4 不安 | 得 | **厄** |
| **ハートで愛を出す** = 愛・感謝駆動 = 第三層ハート起点 | 損 | **徳** |

→ 本 Phase は **損徳得厄の法則の入口**。Course 7 (整える・作る・回す) で経営判断の継続的判定軸として本格適用される。

### 三層モデル上の対応

- **不安・恐怖駆動** = Phase 40202-40203 で identified した第二層 4 不安 (存在価値 / 無能露呈 / 承認喪失 / コントロール喪失) と一致
- **愛・感謝駆動** = 第三層 (ハート起点意図設計 / Course 6 ハートを耕す) の予告
- **混合** = 第二層と第三層が並走している自然な状態 (本書 6-6「ハートで笑うエゴと共に生きる」)
- **安全・要確認 (分類除外)** = 危機兆候・法令上の責務・正当な警戒は二元論で押し潰さない (本書 4-4 三分割モデル: 尊厳は無条件 / 評価は条件付き / 信頼・権限は条件付きで制限されて当然)

### 重要原則

- **「不安=悪 / 愛=善」二元論回避**: 不安が適切な動機になる場面もある (危機兆候・法令上の責務・正当な警戒)
- **本人の実感優先**: 「混合」「分類できない」も genuine な答え。Claude が「絶対どちらかに分類できる」と捻り出さない (シノファンシー注意)
- **第三層 (ハート) は思考停止しても残る (本書 3-5)**: 動機転換は本 Phase で「観察」までで、本格的な転換は Course 6 (ハートを耕す) で起きる
