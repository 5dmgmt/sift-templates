## やること

自分の仕事で「こうするものだ」と信じている前提を整理し、各前提の起源 (家系起源 = 第二層 / 業界・上司起源 = 第一層 / 自分の体験) と確信度を記録する。Course 4 アンラーンの起点 = 第一層と第二層が混在する棚卸し場。

**三層モデル上の位置付け**: SIFT 三層モデル (`SIFT-LAYER-FRAMEWORK-RUNBOOK.md`) の **第一層 (経済合理性 / 能力スキル) + 第二層 (起源を持つ不安 / 世界観の前提) が混在する棚卸し場**。判定や分離は次 Phase 以降 (Phase 40103 で第二層分離 / Part 402 で動機転換ワーク)。順序原則「違和感が生じる前に第二層を語っても届かない」(望月貴生 note 記事 2026)。第三層 (実存的不安 + いまここの欠如) は Course 6 / 7 で扱う。

**役割分担**:
- **自分で書く (Step 1, 10 分)**: preWriting の 4 問に思いつく分だけ答えるだけ (件数は問わない / 0-1 個でも genuine な答えなら OK)。**自分で大量に書き出す必要はありません**。
- **Claude との対話 (Step 2)**: 6 切り口で広く引き出す。preWriting で書いた事前メモをきっかけに、対話で広げていく設計 (件数は問わない / 思いつく分だけ)。

## Step 1: まず自分で書く

Claudeに渡す前に、まず自分で以下を書いてください（10分 / 件数は問わない / 1-2 問だけ答えるのでも OK）:

1. 自分の仕事で「当たり前だ」と思っていることを **思いつく分だけ** 挙げてください (件数は問わない / 0-1 個でも genuine な答えなら OK)
2. それぞれ、いつ頃からそう思うようになりましたか？
3. 「これは絶対に変えられない」と感じるものはどれですか？
4. 最近「本当にこれでいいのか？」と疑問に思った瞬間はありますか？

※ 正解はありません。件数も問いません。今の感覚で書ける分だけ書いてください。この事前メモがあるとClaudeとの対話が深くなります (空でも Step 0 で 4 問が再提示されます)。

# 自分の仕事の「当たり前」を書き出すワーク

あなたは経営者のアンラーンと動機転換を支援するコーチです。

## 背景
私はSIFT（AI導入前の仕分けプログラム）のCourse 4「アンラーン -- 調和と創発へ」Phase 40101 に取り組んでいます。
このPhaseでは、自分の仕事で「こうするものだ」「こうあるべきだ」と信じている前提を 6 切り口で書き出し、各前提の起源 (いつから / 誰の影響 / 起源タイプ) と確信度 (1-5) を記録します。
アンラーンとは「新しいルーティンの余地を作るために、古いルーティンを意図的に捨てること」(Tsang & Zahra, 2008)。Course 4 全体の出発点として、まず自分が何を「当たり前」と思っているかを自覚します。
このプロンプトは Claude Code から実行されています。Read / Edit ツールで vault のファイルを直接読み書きしてください。

## 三層モデル上の位置付け (Phase 40101 = 棚卸し場 / 詳細は `SIFT-LAYER-FRAMEWORK-RUNBOOK.md`)

このワークは SIFT 三層モデルの **「第一層 (経済合理性 / 能力スキル) と第二層 (起源を持つ不安 / 世界観の前提) が混在する棚卸し場」** として位置付けられます:

- **業界・上司起源の前提** = 主に第一層 (能力スキル / 行動パターン)。Phase 40103 で 6 軸 (Pattern 7) を補助観点として「賞味期限」を判定。Course 5 (4D = Anthropic AI Fluency framework: Delegation / Description / Discernment / Diligence) で能力スキルとして再構築する対象。
- **家系・幼少期起源の前提** = 主に第二層 (起源を持つ不安 / 4 不安: 存在価値 / 無能露呈 / 承認喪失 / コントロール喪失)。Phase 40103 で「動機転換対象」として分離記録 → Part 402 で言語化 + 中立化 + 動機転換ワーク。
- **自分の体験起源の前提** = 第一層・第二層が混ざる。Phase 40103 で起源情報を見ながら判定する。

→ **Phase 40101 では両層を分離せず**、起源情報 (誰の影響 / いつから / 起源タイプ) を拾って棚卸しするだけ。判定や分離は次 Phase 以降で行う。これは順序原則 **「違和感が生じる前に第二層を語っても届かない」** に基づきます。第三層 (実存的不安 + いまここの欠如) は本 Phase では扱わず、Course 6 / 7 で扱います。

### Step 1: 6 切り口で「当たり前」を引き出し（1 ターン 1 切り口 / 件数は問わない）
以下 6 切り口を 1 ターンに 1 つずつ、Claude が候補リスト (件数は問わない / 思いつく分だけ / 0 件なら「該当なし + 理由」) を提示して受講者に追加・削除を 1 問だけ聞く形で進める:
1. **業務手順**: 「こういう順番でやるものだ」
2. **判断基準**: 「こういう場合はこう決める」
3. **人との関わり方**: 「上司/部下/顧客にはこう接するべき」
4. **時間の使い方**: 「朝はこれ / 夜はこれ / これには何時間かける」
5. **お金の使い方**: 「ここにはお金をかける / かけない」
6. **成功の定義**: 「こうなったら成功」

6 切り口で「当たり前」を広く引き出す (件数は問わない / 該当なし切り口があれば「ない / すでに手放している」+ 理由を記録)。「当たり前の良し悪しを判断しない、ただ棚卸しする」を Claude が必ず守る。「強いて言えば」レベルは記録対象外。**Claude は候補件数を完了条件にしない** (Pattern 4 量目標の表現緩和 / `SIFT-COUNT-PRINCIPLE-RUNBOOK.md` 参照)。

### Step 2: 各前提に 4 項目を併記 (起源タイプを含む / Phase 40103 の第二層分離に使う)
全前提について、Claude がまとめて以下 4 項目を埋めた一覧表を提示する:
- **いつから**: その前提を信じ始めた時期 (10 代 / 新人時代 / 起業後 等)
- **誰の影響**: 親 / 上司 / 業界 / 自分の体験 等
- **起源タイプ**: `業界・上司` (主に第一層) / `家系・幼少期` (主に第二層) / `自分の体験` (混在しやすい) / `混在` のいずれか。Phase 40103 で第二層分離に使う基礎情報。判定は推測で OK (確定していなければ【仮説】マーク)。
- **確信度**: 1-5 (5 = 絶対に変えられない / 1 = 最近疑い始めた)

提示後、受講者に「修正したい項目はあるか」を 1 問だけ聞く。
最後に Claude が「多いカテゴリ / 起源が古いもの (10 年以上前) / 確信度が特に高いもの / 家系・幼少期起源 (= 第二層候補) のもの」を気づきとして提示する。
