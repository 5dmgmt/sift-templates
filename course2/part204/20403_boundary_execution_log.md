# 人の手放し対話・実行ワーク

私はSIFT（AI導入前の仕分けプログラム）のCourse 2「手放しの設計」Phase 20403 に取り組んでいます。
前回の Phase 20402 で境界線を設計しました。今回は最優先 1-3 関係についてメッセージ草案 + 反応シナリオ 3 通りを作り、Day 1 に 1 件を実行します。

## 進め方（私に確認を取らずに開始してください）

### Step 0: 作業ファイル + 参照ファイルを読み、必要情報を揃える
1. **作業ファイル** `~/sift/course2/part204/20403_boundary_execution_log.md` を Read で開き、Step 1 セクションの事前メモを取得
2. **参照ファイル** `~/sift/course2/part204/20402_boundary_design.md` を Read で開く。
   - Step 3 の境界線設計書が空欄 or テンプレのままの場合、ここで停止して受講者に「Phase 20402 を先に完遂してください」と伝える
3. 事前メモが空欄なら、以下 3 問をまとめて 1 度に提示し、私の答えを待つ（A/B/C 選択肢は出さない）:
   - 20402 の境界線設計で、最も優先度が高い相手を 1-3 人選ぶ
   - その人に伝えるとき、一番怖いことは何か？
   - 「伝えた後にどうなってほしいか」の理想は？
4. 必要情報が揃ったら確認や進め方ヒアリングをはさまず即 Step 1 へ

### Step 1: 最優先 1-3 関係を確定
20402 と事前メモを踏まえて、Claude が「最優先 1-3 関係」候補を 3 件提示する。
受講者に「この 3 件で進めるか / 入れ替えるものはあるか」を 1 問だけ聞く。
確定したら即 Step 2 へ。

### Step 2: メッセージ草案を作る（1 ターン 1 関係）
1-3 関係それぞれについて、Claude が以下 4 原則を満たすメッセージ草案 (5〜10 行) を提示する:
- 相手を責めない
- 自分の状態と希望を伝える
- 具体的な提案を含める
- 相手にも選択肢を残す

提示後、受講者に「修正したい点はあるか」を 1 問だけ聞き修正する。

### Step 3: 反応シナリオを 3 通り想定（1 ターン 1 関係）
各関係について、Claude が以下 3 シナリオの「相手の反応」と「自分の対応」をまとめた表を提示する:
1. **受け入れてくれた場合**
2. **反発された場合**
3. **無視された場合**

### Step 4: Day 1 の 1 件を実行
1-3 関係のうち最も実行しやすい 1 件を Claude が選んで提案する。
受講者に「これを今日送るか / 別のものに入れ替えるか」を 1 問だけ聞く。
実行が終わったら、Claude が以下を 1 ターンに 1 つずつ聞いて記録する:
- 実行日
- 実際に伝えた内容 (1 行)
- 相手の反応 (1 行)
- 自分の身体反応 (1 行)
- 気持ちの変化 (1 行)
- 次の調整 (1 行)

### Step 5: 成果物を vault に書き戻す
`~/sift/course2/part204/20403_boundary_execution_log.md` の Step 3「成果物」セクションを Edit で書き込む。
- ファイルの Step 1 / Step 2 (このプロンプト) は触らない
- Step 3 の対話対象 1-3 / メッセージ草案 / 想定シナリオ / 実行記録 / 全体の振り返り / 次の Phase へのメモ を埋める
- チェックリストの該当項目に ✓ を入れる
- 上書き前に必ず Read で現状を確認し、Step 3 が書き込み済みなら私に確認

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 私が別途確認すべき点があれば最後にまとめる
- 完璧なメッセージを目指さない。伝えることが目標
