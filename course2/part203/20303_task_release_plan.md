## 完了条件 (件数主義ではない / Phase 30201 と継承)

- 件数主義を採らない。1 区分あたり 0 件 (= 該当なし / すでに任せ済 / 全て最善最適 / 在り方で答えている等の受容応答 + その理由) でも genuine な答えなら完了
- 件数を完了条件として引き出すことは禁止。捻り出した「強いて言えば」レベルの実行は記録対象外 (混入時はそう注記する)
- 本人の実感として湧くもののみ実行

**応答の二重性の見分け (Claude の役割 / Phase 30201 と継承)**:
- **人間的な欲レイヤー**: 表層のやめたい・委任したい等
- **深層の受容レイヤー**: 「すでに任せている / 全て最善最適 / 自分が残すで在り方として答えている」等
- 両方が並走する応答は両方そのまま記録。どちらかに寄せて整理しない

## 進め方（私に確認を取らずに開始してください）

### Step 0: 作業ファイル + 参照ファイルを読み、必要情報を揃える
1. **作業ファイル** `~/sift/course2/part203/20303_task_release_plan.md` を Read で開き、Step 1 セクションの事前メモを取得
2. **参照ファイル** `~/sift/course2/part203/20302_stop_delegate_ai_matrix.md` を Read で開く。
   - Step 3 のマトリクスが空欄 or テンプレのままの場合、ここで停止して受講者に「Phase 20302 を先に完遂してください」と伝える
3. 事前メモが空欄なら、以下 3 問をまとめて 1 度に提示し、私の答えを待つ（A/B/C 選択肢は出さない）:
   - 20302 の仕分けで「即やめる」に入れたもののうち、本当に明日からやめられるものは？
   - 委任したいタスクの相手に、どう伝えるか想像できるか？
   - 「やめたら迷惑がかかる」という恐れはどこから来ているか？
4. 必要情報が揃ったら確認や進め方ヒアリングをはさまず即 Step 1 へ

### Step 1: やめるタスクの停止日 + 関係者連絡文を作る
20302 の「即やめる」タスクについて、Claude が以下を埋めた一覧表を提示する:
- **停止日**: 7 日以内のいずれか
- **関係者への連絡**: 必要な場合は連絡先と短い伝え方の文面 (3〜5 行)

提示後、受講者に「停止日や文面を変えたいものはあるか」を 1 問だけ聞き修正する。

### Step 2: 委任タスクの引き継ぎ文書を作る
20302 の「人に渡す」タスクについて、Claude が以下を 1 ターンに 1 件ずつ埋める:
- **依頼文**: 相手に送るメッセージ (5〜8 行、80% で渡す前提)
- **引き継ぎ手順**: 5 つ以下の箇条書き手順
- **依頼日**: 7 日以内のいずれか

「完璧な引き継ぎを目指さない (80% で渡して、残りは相手が聞いてくる前提)」を Claude が守る。

### Step 3: AI 下書き化タスクのプロンプト雛形を作る
20302 の「AI 下書き化」タスクについて、Claude が以下を埋めた一覧を提示する:
- **プロンプト概要**: そのタスクを Claude に投げる際の依頼文の雛形 (4〜6 行)
- **人間の仕上げ範囲**: 1 行

### Step 4: Day 1 の 1 件を実行
上記 3 区分のうち最も実行しやすい 1 件を Claude が選んで提案する。
受講者に「これを今日実行するか / 別のものに入れ替えるか」を 1 問だけ聞く。
実行が終わったら、Claude が以下を聞いて記録する (1 ターンずつ):
- 実行日
- やったこと (1 行)
- 結果・気づき (1〜2 行)

### Step 5: 成果物を vault に書き戻す
`~/sift/course2/part203/20303_task_release_plan.md` の Step 3「成果物」セクションを Edit で書き込む。
- ファイルの Step 1 / Step 2 (このプロンプト) は触らない

- チェックリストの該当項目に ✓ を入れる
- 上書き前に必ず Read で現状を確認し、Step 3 が書き込み済みなら私に確認

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 私が別途確認すべき点があれば最後にまとめる
- 完璧な引き継ぎを目指さない。80% で渡して、残りは相手が聞いてくる前提
- 件数は問わない / genuine な「やめたい / 委任したい / AI 化したい」のみ (「強いて言えば」レベルは記録対象外)
