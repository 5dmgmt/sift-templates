## やること

カレンダーやチャットを見ながら、本当はやりたくないタスクを整理する。

**役割分担**:
- **自分で書く (Step 1, 10 分)**: preWriting の 4 問に答えるだけ (= 中心となる 1-3 件の手放せないタスクと気持ち)。**自分で大量に書き出す必要はありません**。
- **Claude との対話 (Step 2)**: 7 カテゴリで広く引き出す (件数は問わない)。preWriting の 1-3 件をきっかけに、対話で広げていく設計。

## 完了条件 (件数主義ではない / Phase 30201 と継承)

- 件数主義を採らない。1 カテゴリあたり 0 件 (= 該当なし / すでに着地 / 全て最善最適 / 任せている等の受容応答 + その理由) でも genuine な答えなら完了
- 件数を完了条件として引き出すことは禁止。捻り出した「強いて言えば」レベルの応答は記録対象外 (混入時はそう注記する)
- 本人の実感として湧くもののみ残す

**2 層の見分け (Claude の役割 / Phase 30201 と継承)**:
- **人間的な欲レイヤー**: 表層の願望・引っかかり等
- **深層の受容レイヤー**: 「すでに任せている / 全て最善最適」等
- 両方が並走する応答は両方そのまま記録。どちらかに寄せて整理しない

### Step 1: 7 カテゴリでタスクを洗い出す（1 ターン 1 カテゴリ）
以下 7 カテゴリを 1 ターンに 1 つずつ、Claude が候補リスト 5〜8 件を提示して受講者に追加・削除を 1 問だけ聞く形で進める:
1. **会議/定例**: カレンダーに入っている定期的な会議
2. **Slack/Chat 対応**: チャットでの返信、調整
3. **請求/経理**: 見積、請求、支払い、経費処理
4. **採用/人事**: 面接、評価、1on1
5. **営業/顧客対応**: 提案、フォロー、クレーム対応
6. **運用/保守**: 日常オペレーション
7. **家庭タスク**: 家事、育児、介護関連

7 カテゴリで広く洗い出す (件数は問わない / 該当なしカテゴリは「ない / すでに任せている」+ 理由を記録)。Claude は「仕方ない」で思考停止せず、見落とし領域 (例: メール返信 / 報告書作成 / 取材対応) を追加で指摘する。「強いて言えば」レベルは記録対象外。

### Step 2: 各タスクに 4 項目を付ける
全タスクについて、Claude がまとめて以下 4 項目を埋めた一覧表を提示する:
- **頻度**: 毎日 / 週 1 / 月 1 / 不定期
- **所要時間**: 1 回あたりの時間
- **心理負荷**: 高 / 中 / 低
- **発生理由**: なぜ自分がやっているのか (1 行)

提示後、受講者に「項目に違和感があるタスクはあるか」を 1 問だけ聞き修正する。

### Step 3: 成果物を vault に書き戻す
`~/sift/course2/part203/20301_task_drain_inventory.md` の Step 3「成果物」セクションを Edit で書き込む。
- ファイルの Step 1 / Step 2 (このプロンプト) は触らない
- Step 3 の 7 カテゴリ別タスク一覧 / 集計 / 次の Phase へのメモ を埋める
- チェックリストの該当項目に ✓ を入れる
- 上書き前に必ず Read で現状を確認し、Step 3 が書き込み済みなら私に確認

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 私が別途確認すべき点があれば最後にまとめる
- 「仕方ない」で思考停止しない。すべてのタスクを疑う前提で進める
