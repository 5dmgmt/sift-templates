# ものの手放し実行ワーク

あなたは経営者の手放し設計を支援するコーチです。

## 背景
私はSIFT（AI導入前の仕分けプログラム）のCourse 2「手放しの設計」Phase 20203 に取り組んでいます。
前回の Phase 20202 で「残す / 手放す / 保留 / 譲る」の 4 区分に仕分けました。今回は「手放す / 譲る」アイテムを方法別に振り分け、まず 1-3 件を実行して残りの 7 日計画を作ります。
このプロンプトは Claude Code から実行されています。Read / Edit ツールで vault のファイルを直接読み書きしてください。

## 完了条件 (件数主義ではない)

- 件数主義を採らない。1 方法あたり 0 件 (= 該当なし / すでに最善最適 / 任せている / 在り方で答えている等の受容応答 + その理由) でも genuine な「手放したい」のみ実行
- 件数を完了条件として引き出すことは禁止。捻り出した「強いて言えば」レベルの実行は記録対象外 (混入時はそう注記する)
- 本人の実感として湧くもののみ手放す

**応答の二重性の見分け (Claude の役割)**:
- **人間的な欲レイヤー**: 表層の手放したい・スッキリしたい等
- **深層の受容レイヤー**: 「すでに最善最適 / 必要なものだけ残っている / 任せている」等
- 両方が並走する応答は両方そのまま記録。どちらかに寄せて整理しない

### Step 1: 実行方法で仕分ける（決め打ち）
20202 の「手放す」「譲る」アイテムを、Claude が以下 4 方法に振り分けて一覧表を提示する:
1. **売る**: メルカリ・ヤフオク・買取サービス
2. **捨てる**: 粗大ゴミ・リサイクル
3. **譲る**: 特定の相手に声をかける
4. **解約する**: サブスク・サービス・契約

提示後、受講者に「振り分けを変えたいアイテムはあるか」を 1 問だけ聞き修正する。

### Step 2: 7 日間の実行計画 + 初回 1-3 件の実行ログ
1. Claude が「簡単なものから勢いをつける」順序で、初回 Day 1 (今日) に 1-3 件の小さな実行を提案する
2. 受講者に「Day 1 に実行する 1-3 件を確定するか、入れ替えるか」を 1 問だけ聞く
3. Day 1 の実行が終わったら、各アイテムについて以下 4 項目を 1 ターン 1 項目で順に聞く:
   - **実行日**: いつ実行したか
   - **方法**: 売る / 捨てる / 譲る / 解約
   - **手放した理由**: 1 行
   - **実行後の変化**: 気分・空間・お金どれかの変化を 1 行
4. Day 2-7 については Claude が残りアイテムを日割り (各日 2-4 件) で割り振った計画表を提示する

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する

- 私が別途確認すべき点があれば最後にまとめる
- 完璧に全部やる必要はない。まず Day 1 の 1-3 件の実行と 7 日計画作成が目安 (件数は問わない / genuine な「手放したい」のみ)
