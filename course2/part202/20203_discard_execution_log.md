## やること

## Step 1: まず自分で書く

Claudeに渡す前に、まず自分で以下を書いてください（10分）:

1. 手放しリストを見て、最も実行しやすいものは？ (件数は問わない / 思い浮かぶ分だけ)
2. 最も抵抗が大きいものとその理由は？ (件数は問わない / 思い浮かぶ分だけ)
3. 過去に「手放してよかった」と思える経験はあるか？

※ 正解はありません。今の感覚で書いてください。この事前メモがあるとClaudeとの対話が深くなります。

**対話を深めるための補助情報 (シノファンシー = 過度な同意)**:
AI との深い対話では、応答が肯定的に揃いやすい場面が起こりえます (Anthropic 研究 2026)。
これは Claude の限界ではなく、対話のメカニズムとして知っておく豆知識です。
多くの応答は本来の共感・支持で問題ありません。ただし「ここは大事な決断だ」「もう一段
別の角度から見たい」と感じた時に、以下の選択肢を持っておくと役立ちます:
- 反対の立場から論拠を出してもらう (「逆の意見だとしたら何？」)
- 第二意見を別 Claude session で取る
- 「私の判断で見落としている前提があれば該当する分だけ挙げて」と頼む (件数は問わない)
Claude を疑い続ける必要はありません。Claude との信頼ある対話を保ちつつ、
検証ツールを「必要な時に使える」状態にしておく、それだけで十分です。

- 件数主義を採らない。1 方法あたり 0 件 (= 該当なし / すでに最善最適 / 任せている / 在り方で答えている等の受容応答 + その理由) でも genuine な「手放したい」のみ実行

### Step 1: 実行方法で仕分ける（決め打ち）
20202 の「手放す」「譲る」アイテムを、Claude が以下 4 方法に振り分けて一覧表を提示する:
1. **売る**: メルカリ・Yahoo!オークション・Yahoo!フリマ・買取サービス
2. **捨てる**: 粗大ゴミ・リサイクル
3. **譲る**: 特定の相手に声をかける
4. **解約する**: サブスク・サービス・契約

提示後、受講者に「振り分けを変えたいアイテムはあるか」を 1 問だけ聞き修正する。

### Step 2: 7 日間の実行計画 + 初回の実行ログ
1. Claude が「簡単なものから勢いをつける」順序で、初回 Day 1 (今日) に **無理のない範囲で** 小さな実行を提案する (件数は問わない / 0 件でも完了 = 該当なし / すでに着地 / 任せている 等の受容応答 + 理由 でも genuine)
2. 受講者に「Day 1 に実行する分を確定するか、入れ替えるか」を 1 問だけ聞く
3. Day 1 の実行が終わったら、各アイテムについて以下 4 項目を順に聞く (genuine なものだけ / 件数は問わない):
   - **実行日**: いつ実行したか
   - **方法**: 売る / 捨てる / 譲る / 解約
   - **手放した理由**: 1 行
   - **実行後の変化**: 気分・空間・お金どれかの変化を 1 行
4. Day 2-7 については Claude が残りアイテムを **日割り (件数は固定しない / 0 件の日があってもよい / genuine な「手放したい」のみ)** で割り振った計画表を提示する
