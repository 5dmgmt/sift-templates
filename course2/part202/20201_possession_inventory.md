## Step 1: まず自分で書く

Claudeに渡す前に、まず自分で以下を書いてください（10分）:

1. 自分の持ち物で最も執着があるものは？ (件数は問わない / 思い浮かぶ分だけ)
2. 「持っているだけで重い」と感じるものは？
3. デジタルで整理できていない領域（サブスク、クラウド、アカウント等）は？
4. Part 201 の制約分類で気づいたことは何ですか？

※ 正解はありません。今の感覚で書いてください。この事前メモがあるとClaudeとの対話が深くなります。

**対話を深めるための補助情報 (シノファンシー = 過度な同意)**:
AI との深い対話では、応答が肯定的に揃いやすい場面が起こりえます (Anthropic 研究 2026)。
これは Claude の限界ではなく、対話のメカニズムとして知っておく豆知識です。
多くの応答は本来の共感・支持で問題ありません。ただし「ここは大事な決断だ」「もう一段
別の角度から見たい」と感じた時に、以下の選択肢を持っておくと役立ちます:
- 反対の立場から論拠を出してもらう (「逆の意見だとしたら何？」)
- 第二意見を別 Claude session で取る
- 「私の判断で見落としている前提があれば該当する分だけ挙げて」と頼む (件数は問わない)
Claude を疑い続ける必要はありません。Claude との信頼ある対話を保ちつつ、
検証ツールを「必要な時に使える」状態にしておく、それだけで十分です。

> **危機兆候時の停止条件 (重要)**: 50 アイテム以上の棚卸し + 「手放し候補」化を扱うため、以下が示唆されたら **通常の心理コスト分類に流さない**:
> - 自己危害 / 他害 / 強い解離 / パニック
> - 進行中の **虐待 / ハラスメント / 暴力 / 違法行為 / 権力濫用**
> - **武器 / 違法薬物 / 法的書類 / 共有所有物 / 会社資産** など、安易に「手放し」できないもの
> - 医療・健康に直結する物 (= 処方薬 / 補助具 / 治療機器)
>
> 該当時は分類 / 手放し候補化を **即停止** + 「安全確保 / 関係者 (家族・共同所有者・会社) 確認 / 専門家・法務・医療相談」を最優先。「ものを減らす圧」をかけない。
>
> **補助観点 (シノファンシーと安全確保の関係)**:
> 危機兆候 (DV / ハラスメント / 違法行為強要 / 自己危害 / 解離 等) を扱う時、Claude の応答が
> 共感的になることがあります。**多くは本来の共感で問題ありません**。ただし、Claude の応答が
> 「もう向き合えた / 解決した」と早期に感じさせる方向に傾くことがありえる (Anthropic 2026 研究)
> ことを念頭に、**専門家相談を最優先する原則は維持**してください。Claude との対話で
> 気持ちが整理されることと、専門家による支援を受けることは別の経路で、どちらも必要な時があります。

> - **記録するもの**: サービス名 / 用途 / 所有者 / 月額・年額換算 / 更新日 / 請求履歴確認済みか
> - **記録しないもの**: パスワード / API key / 2FA / recovery code / `SUPABASE_SERVICE_ROLE_KEY` / `sb_secret_` / Supabase JWT / `Authorization` header / `apikey` header / cookie / `op://` 参照 / `.env*` / RLS / migration の生 SQL / `service_role` JWT / 顧客 PII / 個人メール本文
> - **`sb_publishable_` 系の公開 key も値を生で保存せず、「公開 key 種別あり」程度の抽象化に留める**
> - 入力されてしまった場合は **伏せ字化** + 成果物に保存しない（secret 実値検出時は通常保存をやめて停止）

### Step 1: 場所ごとに洗い出す（1 ターン 1 場所 / 件数は問わない / 1 場所あたりの目安上限 25 件）
以下 3 場所を 1 ターンに 1 つずつ、Claude が候補リストを提示して受講者に追加・削除を 1 問だけ聞く形で進める (件数は問わない / 該当なしも genuine):
1. **自宅**: 各部屋 (リビング / 寝室 / キッチン / 浴室 / 玄関 / 収納) の家具・衣類・書籍・雑貨
2. **オフィス**: デスク・備品・書類・ストック・電子機器
3. **デジタル**: サブスクリプション・クラウドストレージ・アカウント・アプリ・メールリスト

3 場所で genuine なアイテムが網羅されるまで深掘りする (件数は問わない / 該当なしも genuine)。少ない場合は Claude が「玄関の靴 / 季節物 / 名刺 / SNS アカウント」など見落とし領域を指摘する。アイテム数が多くなる場合は自宅 / オフィス / デジタルごとに **目安 25 件単位でバッチ化**（残バッチ件数を成果物末尾に記録、次バッチ条件を明記）。

### Step 2: 使用頻度 + 心理コストで分類する
全アイテムについて、Claude がまとめて以下を埋めた一覧表を提示する:
- **使用頻度**: 「毎日 / 週1以上 / 月1程度 / 年1未満 / 1年以上未使用」の 5 段階（純粋な頻度のみ）
- **心理コスト**: 「持ち続けることの精神的負荷（持っているだけで重い等）」を 高 / 中 / 低 で評価
- **メモ**: 任意の補足 (壊れている / 思い出 / 義務感など)

提示後、受講者に「分類に違和感があるアイテムはあるか」を 1 問だけ聞き修正する。
