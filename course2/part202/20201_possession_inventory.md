## 進め方（私に確認を取らずに開始してください）

### Step 0: 作業ファイルを読み、必要情報を揃える
1. `~/sift/course2/part202/20201_possession_inventory.md` を Read で開き、Step 1 セクションの事前メモを取得
2. 任意参照ファイル `~/sift/course2/part201/20103_constraint_reality_check.md` を Read で開く。存在しない or 空欄でも続行可
3. 事前メモが空欄なら、以下 4 問をまとめて 1 度に提示し、私の答えを待つ（A/B/C 選択肢は出さない）:
   - 自分の持ち物で最も執着があるものは？ (件数は問わない / 思い浮かぶ分だけ)
   - 「持っているだけで重い」と感じるものは？
   - デジタルで整理できていない領域は？
   - Part 201 の制約分類で気づいたことは？
4. 事前メモが揃ったら確認や進め方ヒアリングをはさまず即 Step 1 へ

### Step 1: 場所ごとに洗い出す（1 ターン 1 場所 / 件数は問わない / 1 場所あたりの目安上限 25 件）
以下 3 場所を 1 ターンに 1 つずつ、Claude が候補リストを提示して受講者に追加・削除を 1 問だけ聞く形で進める (件数は問わない / 該当なしも genuine):
1. **自宅**: 各部屋 (リビング / 寝室 / キッチン / 浴室 / 玄関 / 収納) の家具・衣類・書籍・雑貨
2. **オフィス**: デスク・備品・書類・ストック・電子機器
3. **デジタル**: サブスクリプション・クラウドストレージ・アカウント・アプリ・メールリスト

3 場所で genuine なアイテムが網羅されるまで深掘りする (件数は問わない / 該当なしも genuine)。少ない場合は Claude が「玄関の靴 / 季節物 / 名刺 / SNS アカウント」など見落とし領域を指摘する。

### Step 2: 使用頻度 + 心理コストで分類する
全アイテムについて、Claude がまとめて以下を埋めた一覧表を提示する:
- **使用頻度**: 「毎日使う / 月 1 使う / 1 年使っていない / 持っているだけで重い」の 4 段階
- **心理コスト**: 「持ち続けることの精神的負荷」を 高 / 中 / 低 で評価
- **メモ**: 任意の補足 (壊れている / 思い出 / 義務感など)

提示後、受講者に「分類に違和感があるアイテムはあるか」を 1 問だけ聞き修正する。

### Step 3: 成果物を vault に書き戻す
`~/sift/course2/part202/20201_possession_inventory.md` の Step 3「成果物」セクションを Edit で書き込む。
- ファイルの Step 1 / Step 2 (このプロンプト) は触らない
- Step 3 の自宅 / オフィス / デジタル 3 表 / 集計 / 次の Phase へのメモ を埋める
- チェックリストの該当項目に ✓ を入れる
- 上書き前に必ず Read で現状を確認し、Step 3 が書き込み済みなら私に確認

## ルール
- **進め方の確認・好みヒアリングは禁止**。上記の手順で決め打ちで進める
- **質問は 1 ターンに 1 つだけ**。複数選択肢の提示や複数項目の同時質問は禁止
- 根拠がある部分と、推測の部分を分けて出力する
- まだ確定していない暫定判断には【仮説】マークをつける
- 私が別途確認すべき点があれば最後にまとめる
- 数は正確さより網羅性を重視。思い出せる限り出す
